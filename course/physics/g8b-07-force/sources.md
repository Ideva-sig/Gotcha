## 3. 冲突与取舍

| 内容 | 情况 | 取舍 |
| --- | --- | --- |
| 不接触也能产生力的作用 | 课本 p.2 仅举出磁体吸引铁钉的事例，未出现“两个物体不一定要接触才有力的作用”原话 | 7.1a“容易错”归纳该结论，登记为推论。 |
| 7.1b 的题目覆盖 | 课本 7.1 练习第 3 题要求举例说明方向的影响，第 4 题才是画力的示意图 | 选第 3 题只练方向对作用效果的影响；力的示意图方法在正文中讲，未声称这道练习覆盖作图。 |
| 弹簧伸长量与拉力的关系 | 课本 p.8 只明确说在弹性限度内，拉力越大，伸长量越大；地图的 2a 前置理由保留“伸长量与拉力成正比” | 讲义照课本写一般关系，不把它写成普遍的正比定律。GZ2024-18(1)只从题中这根弹簧的 $F$-$x$ 直线图读出比值 $k=F/x$。 |
| 弹簧测力计改变测量方向 | 课本 p.8 实验第 4 步只写了悬挂和水平拖动文具袋的测量，未单独强调调零 | “走一遍”第 4 步以括号单独提示“由竖直方向转为水平方向测量前，要按新的测量方向重新检查指针并调零”，作为实验操作注意点，登记为推论。 |
| Q-PHY-GD2023-23-1 竖直调零依据 | 原卷解析理由为“竖直下拉防止卡壳”，且原题第（2）问才有挂物块图 | 本章只摘录第（1）问，解析补充“本实验后面要把物块竖直挂在测力计下测量”，使设问理由自洽。 |
| Q-PHY-GZ2024-18-1 配图范围说明 | 原卷题图包含图甲、乙、丙，作答第（1）问仅需图甲 | 题干保留原图，并在第（1）问后注明“（本问只用图甲）”，明确作答范围。 |
| GD2023-24(1) 飞机质量数值 | 解析版 Word 文字层识别存在偏差 | 核对原卷矢量图与原题 PDF 确认飞机总质量为 $8\times10^{4}\ \mathrm{kg}$，计算重力为 $8\times10^{5}\ \mathrm{N}$，严格按原卷订正。 |
| 重力数值核对 | 课本 PDF 文字层的公式和上下标存在识别风险 | 对照课本 p.13 原页图核实公式和数值，讲义中的课本数值依原页书写。 |
| 斜面上重力的方向 | 课本未画出斜面上物体受力，但中考常考斜面上重力方向易错点 | 7.3b“容易错”提示“物体放在斜面上，重力仍然竖直向下，不是垂直于斜面”，登记为推论。 |
