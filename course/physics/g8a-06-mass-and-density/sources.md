## 3. 冲突与取舍

| 内容 | 情况 | 取舍 / 推论登记 |
| --- | --- | --- |
| 6.1a 质量不随温度改变 | 课本 p.140 只列了形状、物态和位置；“不随温度改变”是真题（GD2022-10、GD2024-02 原卷解析）常用概念 | 采用，在“容易错”中补充，登记为推论 |
| 6.1b 调平口诀与称量中不能动螺母 | 课本正文未直接写“指针偏向分度盘哪一侧，平衡螺母就向相反方向调”；称量中不能动平衡螺母也是真题实验考点 | 采用，补充在“先认住”、“走一遍”和“容易错”中，登记为推论 |
| 6.2a 单位换算说法 | 初稿写了边长类比，前后矛盾且非课本内容 | 删去边长类比，只保留 $1\ \mathrm{g/cm^3}=10^3\ \mathrm{kg/m^3}$ 与纯水密度实例 |
| 6.2a 密度与温度性质 | 课本 p.154 指出密度是物质的基本性质之一；p.147 科学世界讲解了密度受温度影响及水在 4 ℃ 密度最大 | 采用课本原话提炼放入“先认住”，与前置自查热胀冷缩呼应 |
| 6.3a 液体密度测量误差分析 | 课本 p.149 给出表格法测液体密度。先测空烧杯再倒液体会因残留导致质量偏小、密度偏小；课本测总质量再测剩余质量，倒出的质量和体积都是直接测量值 | 删去初稿“剩余法”等自创名词，按课本实际操作描述误差，登记为推论 |
| 前置自查与体积单位换算 | 课本第一章无体积单位；p.151 练习第 2 题给出 $1\ \mathrm{L}=1\ \mathrm{dm^3}$ | 前置自查改为“知道 $1\ \mathrm{L}=1\ \mathrm{dm^3}$，$1\ \mathrm{mL}=1\ \mathrm{cm^3}$”，不指向第一章；“$1\ \mathrm{mL}=1\ \mathrm{cm^3}$”登记为推论 |
| 6.4a 计算中单位必须配套 | 课本未单独总结单位配套口诀，但例题计算严格区分两套单位 | 在“容易错”中强调 $\mathrm{kg/m^3}$ 配 $\mathrm{kg}$ 与 $\mathrm{m^3}$、$\mathrm{g/cm^3}$ 配 $\mathrm{g}$ 与 $\mathrm{cm^3}$，登记为推论 |
| 6.4a“走一遍”数据精度取舍 | 本项目严格计算为 $0.019625\ \mathrm{m}^3$，课本 p.147 例题取约 $0.02\ \mathrm{m}^3$ 并算得 $54\ \mathrm{kg}$ | 沿用课本数值，约掉的单位用 `\cancel{...}` 划掉，并在算式后补充说明“课本把体积取作约 0.02 m³，所以结果是 54 kg” |
| Q-PHY-GD2024-23 第（3）问解析 | 题目通过加凉茶使液面重新上升到标记 $M_2$ 来等效李子体积 | 解析补充“液面回到标记处，加进去的凉茶体积就等于李子的体积”，由等效替代推得，登记为推论 |

- 6.1a“温度改变，质量也不变”课本 p.140 只写形状、物态、位置，温度来自真题解析，登记为推论。6.1b 调平口诀作为“**补充**”保留（2026-10-06 项目负责人同意）。6.1b“走一遍”用指针偏左，练一练 TB8A-06.1-3 是偏右，避免先给答案。
