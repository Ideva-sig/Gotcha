# 第六章 质量与密度

本章导语：探讨物体“轻与重”的本质。我们将学习质量和密度的概念，掌握使用天平和量筒测量它们的方法，并学会用密度来鉴别物质。

## 本章前置自查

- 知道 $1\ \mathrm{L}=1\ \mathrm{dm^3}$，$1\ \mathrm{mL}=1\ \mathrm{cm^3}$。
- 了解物体具有热胀冷缩的特性（第三章）。

## 6.1a 质量的概念与单位

```yaml

prerequisites: []
evidence:
  - 能记住质量的基本单位和常用单位的换算
  - 能判断物体的质量是否随位置、形状、状态的改变而改变
figure: 不需要
sources:
  - 课本 p.139–140
```

### 本次只学

认识什么是质量，记住质量的单位，并知道它不随外界条件改变。

### 先认住

- 物体所含物质的多少叫作**质量**，通常用字母 $m$ 表示。基本单位是**千克**，符号是 $\mathrm{kg}$。
- 质量的常用单位换算：$1\ \mathrm{t} = 10^3\ \mathrm{kg}$，$1\ \mathrm{g} = 10^{-3}\ \mathrm{kg}$，$1\ \mathrm{mg} = 10^{-3}\ \mathrm{g}$。
- 物体的质量不随它的形状、物态和位置而改变。

### 容易错

- 误以为物体受热、被压扁或熔化后质量会变：不管怎样变形或变态，物质的多少没有变，质量就不变；温度改变，质量也不变。
- 误以为宇航员到太空后质量会变：质量与所处的位置无关，在地球和太空中质量是相同的。

## 6.1b 托盘天平的使用和读数

```yaml
id: PHY-8A-06-1b
weight: 重点
weight_note: 5 次读数、调平，且是 2026 广州实验操作考试题目
textbook: 八上 6.1 质量，p.141–142

  - id: PHY-8A-06-1a
    strength: hard
    reason: 天平测的是质量
evidence:
  - 能正确描述调节天平平衡的步骤
  - 能根据砝码和游码的位置读出物体的质量
figure: 不需要
sources:
  - 课本 p.141–142
```

### 本次只学

掌握实验室里用托盘天平测量质量的操作步骤，并学会读数。

### 先认住

- 调平：把天平放在水平桌面上，游码移到标尺左端的零刻度线处；调节横梁上的平衡螺母，使指针指在分度盘的中线处。
- **补充**（课本没有讲，做真题时常用）：指针偏向分度盘哪一侧，平衡螺母就向相反方向调。
- 称量：左盘放物体，右盘用镊子加减砝码，并调节游码直到横梁恢复平衡；被测物体的质量不能超过天平的称量。
- 读数：被测物体的质量等于盘中砝码的总质量加上游码左端在标尺上所对应的质量。

### 走一遍

**称量前调节天平横梁平衡**

以称量前指针偏向分度盘左侧为例：

1. **放水平与游码归零**：把托盘天平放在水平桌面上，把游码移到标尺左端的零刻度线处。
2. **观察指针**：指针偏向分度盘中线左侧，说明左端偏重。
3. **调节螺母**：向右调节平衡螺母，直到指针指在分度盘中线处，横梁平衡。

### 容易错

- 称量物体时误调平衡螺母：称量过程中只能加减砝码和调节游码，不能再动平衡螺母。
- 游码读数看错边：一定要以游码左侧边缘对准的刻度为准，不能看右侧。

## 6.2a 密度的概念

```yaml
id: PHY-8A-06-2a
weight: 一般
weight_note: 2 次（材料选择、轻质材料）
textbook: 八上 6.2 密度，p.144–147；p.154
prerequisites:
  - id: PHY-8A-06-1a
    strength: hard
    reason: 密度由质量和体积定义
  - id: MATH-比例
    strength: soft
    reason: 同种物质质量与体积成正比
evidence:
  - 能说出密度的公式和单位
  - 知道密度是物质的特性，通常与体积和质量的多少无关
figure: 不需要
sources:
  - 课本 p.144–146
```

### 本次只学

理解密度的物理意义，记住密度的公式和常用的两个单位。

### 先认住

- 某种物质组成的物体的质量与它的体积之比叫作这种物质的**密度**，公式为 $\rho=\frac{m}{V}$。密度是物质的基本性质之一，每种物质都有自己的密度。
- 在国际单位制中，密度的单位是千克每立方米（$\mathrm{kg/m}^3$）。常用的单位还有克每立方厘米（$\mathrm{g/cm}^3$）。换算关系：$1\ \mathrm{g/cm}^3=1\times10^3\ \mathrm{kg/m}^3$。纯水的密度为 $1.0\times10^3\ \mathrm{kg/m}^3$。
- **密度与温度**：温度能够改变物质的密度。一般来说，同种物质温度越高密度越小，遵从热胀冷缩的规律；但水比较特殊，水在 4 ℃ 时密度最大，水凝固成冰时体积变大、密度变小。

### 容易错

- 误以为质量越大，密度就越大：同种物质的质量与体积之比是一定的，密度不随物体的质量或体积而改变。
- 密度单位换算弄反：$1\ \mathrm{g/cm^3}=10^3\ \mathrm{kg/m^3}$，例如水的密度 $1\ \mathrm{g/cm^3}=1.0\times10^3\ \mathrm{kg/m^3}$。

## 6.3a 测量液体和固体的密度

```yaml
id: PHY-8A-06-3a
weight: 重点
weight_note: 6 次，实验题常考，含误差分析
textbook: 八上 6.3 测量液体和固体的密度，p.149–150
prerequisites:
  - id: PHY-8A-06-1b
    strength: hard
    reason: 要用天平测质量
  - id: PHY-8A-06-2a
    strength: hard
    reason: 实验原理是 ρ=m/V
evidence:
  - 能写出测量液体和固体密度的步骤
  - 能根据实验数据计算出密度
  - 能分析实验步骤中的操作会导致测量结果偏大还是偏小
figure: 不需要
sources:
  - 课本 p.149–150
```

### 本次只学

掌握用天平和量筒测量固体、液体密度的实验方法。

### 先认住

- **测量液体密度的步骤**：先测出烧杯和液体的总质量 $m_1$；把部分液体倒入量筒，读出体积 $V$；测出烧杯和剩余液体的质量 $m_2$；计算出倒出液体的质量 $m=m_1-m_2$，再求出密度 $\rho=\frac{m}{V}$。
- **测量固体密度的步骤**：先用天平测出不吸水的小石块的质量 $m$；用量筒装适量的水，读出体积 $V_1$；把小石块完全浸没在水中，读出总体积 $V_2$；算出小石块的体积 $V=V_2-V_1$，再求出密度 $\rho=\frac{m}{V}$。
- 量筒读数时，视线要与液面相平。

### 走一遍

**测量盒装牛奶的密度**

课本 6.3 练习与应用第 5 题：某同学想测量盒装牛奶的密度。他把一盒牛奶放在天平上，测出总质量为 $270.0\ \mathrm{g}$；把牛奶倒入量筒 $30\ \mathrm{mL}$ 后，测得剩余部分的质量为 $238.5\ \mathrm{g}$。这种盒装牛奶的密度是多少？

**步骤分析**：
倒入量筒中的牛奶质量 $m=\textcolor{#287fc4}{270.0}\ \mathrm{g}-\textcolor{#287fc4}{238.5}\ \mathrm{g}=31.5\ \mathrm{g}$
倒入量筒中的牛奶体积 $V=\textcolor{#287fc4}{30}\ \mathrm{mL}=30\ \mathrm{cm}^3$
根据密度公式，牛奶的密度为：
$\rho=\frac{m}{V}=\frac{\textcolor{#287fc4}{31.5}\ \mathrm{g}}{\textcolor{#287fc4}{30}\ \mathrm{cm}^3}=\boxed{1.05\ \mathrm{g/cm}^3}$

### 容易错

- 先测固体体积，再测质量：固体从水中拿出来时会沾有水，导致测出的质量偏大，算出的密度偏大。要先测质量再测体积。
- 测液体时如果先用量筒量出体积，再倒入已称过质量的空烧杯：量筒壁上会残留液体，导致测出的质量偏小，算出的密度偏小。课本的做法是先测烧杯和液体的总质量，把一部分倒进量筒读体积，再测烧杯和剩余液体的质量，倒出部分的质量和体积都是量出来的。

## 6.4a 用密度求质量、体积，鉴别物质

```yaml
id: PHY-8A-06-4a
weight: 重点
weight_note: 3 次直接考；液体压强、浮力计算里常要先用 m=ρV
textbook: 八上 6.2 例题 p.147；6.4 密度的应用，p.152–154
prerequisites:
  - id: PHY-8A-06-2a
    strength: hard
    reason: 要用 ρ=m/V 及其变形
  - id: PHY-8A-01-1a
    strength: soft
    reason: 要用测出的长度算体积（如圆柱体积）
evidence:
  - 能根据密度公式变形求物体的质量或体积
  - 能通过计算物体的密度来鉴别物质种类
figure: 不需要
sources:
  - 课本 p.152–154
```

### 本次只学

灵活运用密度公式 $\rho=\frac{m}{V}$ 的变形公式进行计算。

### 先认住

- 利用密度求质量：$m=\rho V$。
- 利用密度求体积：$V=\frac{m}{\rho}$。
- 利用密度鉴别物质：测出物体的质量和体积，求出它的密度，再跟密度表中的数值进行比较。

### 破题钥匙

```think
现象: 同种物质，体积越大质量越大，质量与体积的比值不变
模型: 以 $V$ 为横轴、$m$ 为纵轴，点落在一条过原点的直线上；体积相同时，直线越陡质量越大
图: phy-a-mv-graph
关系: $\rho=\dfrac{m}{V}$
招: 画图
结: 过原点的直线越陡，密度越大
```

### 走一遍

**利用密度求出质量**

课本正文例题：已知铝棒的直径 $d$ 为 $0.1\ \mathrm{m}$，长 $l$ 为 $2.5\ \mathrm{m}$，铝棒的质量是多少？（铝的密度为 $2.7\times10^3\ \mathrm{kg/m}^3$）

**计算过程**：
根据圆柱体体积公式，铝棒的体积为：
$V=\pi \left(\frac{d}{2}\right)^2 l=3.14\times\left(\frac{\textcolor{#287fc4}{0.1}\ \mathrm{m}}{2}\right)^2\times\textcolor{#287fc4}{2.5}\ \mathrm{m}\approx0.02\ \mathrm{m}^3$
根据公式 $\rho=\frac{m}{V}$，推导出 $m=\rho V$，铝棒的质量为：
$m=\rho_{\text{铝}}V=\textcolor{#287fc4}{2.7\times10^3}\ \mathrm{kg}/\cancel{\mathrm{m}^3}\times\textcolor{#287fc4}{0.02}\ \cancel{\mathrm{m}^3}=\boxed{54\ \mathrm{kg}}$

课本把体积取作约 0.02 m³，所以结果是 54 kg。

### 容易错

- 代入数据前没有统一单位：公式中的单位必须配套。如果是 $\mathrm{kg/m}^3$，质量必须用 $\mathrm{kg}$，体积必须用 $\mathrm{m}^3$；如果是 $\mathrm{g/cm}^3$，质量必须用 $\mathrm{g}$，体积必须用 $\mathrm{cm}^3$。不能混用。
