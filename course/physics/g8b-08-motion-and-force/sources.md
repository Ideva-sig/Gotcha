## 3. 冲突与取舍

| 内容 | 情况 | 取舍 |
| --- | --- | --- |
| 惯性的含义 | 课本 p.21 说惯性是物体保持原来匀速直线运动状态或静止状态的性质，是固有属性，跟受力情况及运动状态无关；没有说“惯性大小只与质量有关” | 讲义只写课本明确给出的内容，不加入惯性大小与质量关系。 |
| “惯性不是力” | 课本把惯性定义为一种性质，地图也指出“受到惯性”是常见错误说法 | 讲义按课本定义提示不能说物体“受到惯性”；这是对定义的直接表述。 |
| 滑动摩擦力影响因素 | 课本 p.29 写明压力、接触面粗糙程度和接触面材料都会影响滑动摩擦力，并明确压力越大、接触面越粗糙时摩擦力越大 | 讲义照课本写；对材料只写“有关”，不擅自概括具体增减关系。 |
| GZ2023-13(1) 数值 | 题干的运动距离、用时和两次拉力数值在题图中 | 采用从原卷 DOCX 提取并亲眼查看的题图数值：$MN=0.3\ \mathrm{m}$、$PQ=0.4\ \mathrm{m}$、$F_1=1\ \mathrm{N}$、$F_2=0.6\ \mathrm{N}$；逐项用 Python 重算速度和摩擦力比较。 |
| GD2022-23(2) 题图 | 原卷配有机器人外观照片，但质量、接触面积、速度和阻力条件都在题干里 | 题图不提供作答数据，按规则略去装饰照片，并从题干删去“图中”指代。 |
| 分析受力时“先选定研究对象……” | 课本未明确以此表述作为步骤总结 | 登记为课本外推论，做真题常用。 |
| 测摩擦力“按水平方向调零” | 课本 7.2 仅说调零，未强调“水平方向” | 登记为课本外推论，做真题常用。 |
| 平衡力与相互作用力的区分 | 课本无直接对比 | 登记为推论。 |
| 8.2b“容易错”：平衡的两个力，示意图中两条箭头线段要画得一样长 | 课本没有这句 | 取自 GD2023-15 原卷解析，登记为推论 |
| 8.2b“先认住”某一方向只受两个力时的一般说法 | 课本 p.25 只有列车、跳伞等例子 | 概括为一般说法，登记为推论 |
| 8.4a“两个力大小相等、方向相反，合力等于 0，二力平衡” | 课本 p.35 是列车牵引力与阻力的例子 | 概括为一般说法，登记为推论 |
| 选项含有未学术语 | GD2023-03 选项 C、D 有“压强”（第九章） | 选项含后学术语，不影响选 B。 |
