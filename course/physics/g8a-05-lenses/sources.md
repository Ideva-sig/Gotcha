## 3. 冲突与取舍

- **1a 与 1b 选题**：1a 选入课本习题 `Q-PHY-TB8A-05.1-6`（装水瓶子聚光引发火灾，考查凸透镜会聚作用与森林防火生活常识）；1b 选入真题 `Q-PHY-GZ2023-11`（按 FORMAT 仅做非作图的第 2、3、4 空）以及课本习题 `Q-PHY-TB8A-05.1-5`（利用焦点与光路可逆得到平行光）。
- **2a 与 3b 题目调整**：原 2a 题 `GD2024-09` 第三空考查“物远像近像变小”，移入 3b；2a 改用 `Q-PHY-SZ2023-08`，作答无需看图，故不放照片并删去题干“如图”指代，逐项核对选项均未超纲；3b 保留 `GD2024-09` 和 `GD2023-22-3`，将同类型的 `GZ2025-05` 移至备选。
- **题目拆分使用**：`GD2023-22` 是一道综合了 3a 和 3b 的实验大题。拆分为 `Q-PHY-GD2023-22-2`（归入 3a）和 `Q-PHY-GD2023-22-3`（归入 3b）两道独立题使用。
- **推论清单**：
  1. “物近像远像变大”口诀：课本无原话，但中考高频考查物距变化时像与像距的变化，由成像规律归纳得出。
  2. 3b 像距范围 $f<v<2f$、$v>2f$：课本 p.124“想想议议”仅提问像距范围，讲义按实验总结补充具体范围。
  3. 第三条特殊光线（过焦点的光线经凸透镜折射后平行于主光轴）：课本正文只画出平行光过焦点与过光心两条，第三条由课本习题 5.1-5 及第四章折射光路可逆推出。
  4. 3b“成虚像时物近像也近、像变小”：课本未直接给出口诀，作为“物近像远像变大”仅适用于成实像的反向辨析推论，列入“容易错”。
  5. 3a“像偏上说明蜡烛偏低，应把蜡烛往上调”：由凸透镜成倒立实像的几何光路推出。

- 主会话定稿调整：`Q-PHY-GZ2023-11` 的缩小、倒立两空要用 5.3 成像规律，整题（第②问）从 1b 移到 3b，题干删去第①问作图；`Q-PHY-GD2024-09` 移入备选（3b 只留 2 道）。`Q-PHY-SZ2023-08` 放回原卷题图（大楼与水中倒影，不放则题干和选项 C、D 没有指代），原卷 B 选项错字“程”改为“成”。
- 推论补记：3b 删去“u=2f 等大”一条（课本 p.124 有，但不常考，且原写法嵌在投影仪条下易误解）；3a“像偏上是蜡烛相对透镜偏低”课本没有原话。

## 4. 看过但没采用的内容

- **第 5 节跨学科实践“制作望远镜”（p.130–133）**：课标跨学科实践活动，不拆设考点，不进讲义。
- **课本没有“显微镜”一节**：2022 年课标修订版教材删去旧版显微镜独立小节，仅在正文光学仪器中略有提及，讲义不再设置该考点。
- **真题 GD2023-22(5)（控制变量法探究像与透镜直径关系）**：属于非常规课外规律探究，考查控制变量思维而非凸透镜基础成像规律，3a 讲义正文不予覆盖。
- **作图题真题 `GZ2022-11`、`GZ2024-11(2)`、`SZ2023-12`**：均为纯作图题，暂不进入题库。
- **未引用图片清理**：删去原卷 GD2023-22 第 (4) 问配图 `figures/gd2023-22-2.png`。
