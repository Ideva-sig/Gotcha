# 第四章 整式的加减

用字母表示数之后，数和字母相乘得到单项式，单项式相加得到多项式。
这一章学习整式的加减运算：先去括号，再合并同类项，把复杂的代数式化成最简形式。

```yaml
  strength: soft
  reason: 单项式的次数要读出各字母的指数。
evidence:
- 能指出单项式的数字系数，并保留系数的负号。
- 能把所有字母的指数相加求出单项式的次数。
figure: 不需要；用代数式结构标注系数与指数，不另画示意图。
method: []
sources: [TB7A-4.1]
```

### 本次只学

认清单项式中的数字因数（系数）和所有字母的指数之和（次数）。

### 先认住

- 表示数或字母的积的式子叫作**单项式**；单独一个数或一个字母也是单项式。
- 单项式中的数字因数叫作**系数**（只含字母时系数为 $1$ 或 $-1$）；所有字母的指数之和叫作**次数**（非零常数的次数为 $0$，$0$ 没有次数）。
- **补充**（课本没有讲，做真题时常用）：$\pi$ 是常数属于系数的一部分，不能算入次数；常数的指数不能计入单项式次数（如 $2^3x^2$ 的系数是 $8$，次数是 $2$）。

### 容易错

- 字母指数是 $1$ 时容易漏算（例如在 $3xy$ 中，$x$ 与 $y$ 的指数都是 $1$，次数是 $1+1=2$，不能算成 $1$）。
- 分数系数要连同分母一起读出（如 $\dfrac{a}{2}$ 的系数是 $\dfrac{1}{2}$，不是 $1$）。

### 先认住

- 几个单项式的和叫作**多项式**。每个单项式叫作多项式的**项**，不含字母的项叫作**常数项**；每一项都包含它前面的符号。
- 多项式里次数最高的项的次数，叫作这个多项式的**次数**。
- 单项式与多项式统称**整式**。

## 4.2a 同类项与合并法则

```yaml
id: MATH-7A-04-2a
weight: 一般
weight_note: 未单独计次；九套运算辨析题中的同类项多为干扰选项，不计命中，不因后续使用升为重点。
textbook: 七上4.2，印刷p.95–98
prerequisites:
- id: MATH-7A-04-1a
  strength: hard
  reason: 比较字母和指数是否相同，再把系数相加减。
- id: MATH-7A-02-1b
  strength: hard
  reason: 合并后的系数来自有理数加减。
evidence:
- 能准确判断两个单项式是否为同类项。
- 能把多项式中的同类项用分配律合并，字母与指数保持不变。
figure: 不需要；依据课本的同类项定义与分配律讲解，不使用无准确出处的面积拼接模型。
method: []
sources: [TB7A-4.2]
```

### 本次只学

认准所含字母和字母指数都相同的项，把它们的系数相加减。

### 先认住

- 所含字母相同，并且相同字母的指数也相同的项叫作**同类项**；常数项也是同类项。同类项与系数大小无关，与字母顺序无关。
- 把多项式中的同类项合并成一项叫作**合并同类项**。
- **合并同类项法则**：所得项的系数是合并前各同类项的系数的和，字母连同它的指数不变。

### 容易错

- 只有字母和各字母的指数都相同才能合并，不是同类项不能合并（例如 $2a+3b$ 不能写成 $5ab$）。
- 合并时只加减系数，字母的指数不变，不能把指数相加（例如 $a^2+a^2=2a^2$，不能写成 $a^4$）。

## 4.2b 去括号与整式加减

```yaml

weight: 一般
weight_note: 未单独计次；用于解方程和后续分式化简，但这些题的主要考点不在本节。

prerequisites:
- id: MATH-7A-04-2a
  strength: hard
  reason: 去括号后要合并同类项。
- id: MATH-7A-02-2a
  strength: hard
  reason: 去括号使用分配律及有理数乘法的符号规则。
evidence:
- 去括号时能把括号外的乘数乘到括号内的每一项，符号变化正确。
- 能按照“先去括号、再合并同类项”的步骤完成整式加减运算。
figure: 不需要；去括号与合并同类项按代数式推导书写，重点体现正负号变化，不另画示意图。
method: []
sources: [TB7A-4.2]
```

### 本次只学

利用乘法分配律去掉括号，再合并同类项完成整式的加减。

### 先认住

- 括号外的因数是正数，去括号后原括号内各项的符号与原来的符号相同：$+(a-b)=a-b$。
- 括号外的因数是负数，去括号后原括号内各项的符号与原来的符号相反：$-(a-b)=-a+b$。
- **整式加减运算法则**：几个整式相加减，如果有括号就先去括号，然后再合并同类项。

### 容易错

- 括号前面是负号时，去括号时括号内每一项都要变号，不能只变第一项的符号。
- 括号前面有乘数时，乘数必须乘到括号内的每一项，不能漏乘常数项。

```yaml
- 能把给定的字母数值正确代入最简式求出数值。
figure: 不需要；以代数化简与求值步骤为主，不另画几何示意图。
method: []
sources: [TB7A-4.2]
```

### 本次只学

先去括号并合并同类项，化简为最简整式后再代入求值。

### 先认住

- 求多项式的值时，通常**先化简、再求值**：先去括号并合并同类项，化简成最简整式后，再代入数值计算。
- 负数代入乘法或乘方时，用括号标明整个负数；分数作乘方底数时，把整个分数括起来。
- **补充**（课本没有讲，做真题时常用）：若化简后含字母的项全部消去，只剩常数，则代数式的值与字母的取值无关。

### 容易错

- 通常先化简再代入，计算更简便；直接代入也可以，但要注意符号。
- 代入负数时漏加括号（例如 $b=-\dfrac{1}{2}$ 时，$b^2=\left(-\dfrac{1}{2}\right)^2=\dfrac{1}{4}$，若漏加括号会错算成 $-\dfrac{1}{4}$）。
