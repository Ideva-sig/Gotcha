# 第十二章 数据的收集、整理与描述

收集数据先选调查方式，是全面查还是抽样查。整理出的数据，用条形看数量、用折线看趋势、用扇形看占比、用直方图看分组分布。由样本推断总体，用图表解释现实。

## 本章前置自查

1. 能计算百分数以及求出一个数占另一个数的百分比吗？不能：先回看小学百分数的意义与运算。
2. 能根据比例分配总量，或者计算扇形圆心角占 $360^\circ$ 的度数吗？不能：先回看小学比和比例。
3. 能在平面直角坐标系中根据坐标描出点的位置吗？不能：先回看第七章平面直角坐标系。

### 本次只学

分清全面调查与抽样调查，认准总体、个体、样本与样本容量。

### 先认住

- 全面调查收集数据全面准确，但花费多、耗时长；抽样调查花费少、省时省力，但抽取的样本必须具有代表性和广泛性。
- 所要考察对象的全体称为总体，组成总体的每一个考察对象称为个体。
- 从总体中抽取的那部分个体称为样本，样本中包含的个体的数目称为样本容量。

## 12.1b 用样本比例估计总体

```yaml
id: MATH-7B-12-1b
title: 用样本比例估计总体
weight: 一般
weight_note: 九套卷直接命中2次，为人数填空和人数估计小问；方法是样本比例乘总体数，解释估计不等于确数，不把平均数或方差分析转记本点。
textbook: 七下 12.1，印刷p.154–159
prerequisites:
- id: MATH-7B-12-1a
  strength: hard
  reason: 必须区分样本人数与总体人数，才不会使用错误的比例基数。
evidence:
- 能根据样本中某类对象的频数或百分比，估计总体中的对应人数。
- 能说清样本估计总体的结果是估计值，不是确切值。
figure: 可选·图解步骤：从“样本中的百分比”到“总体中对应数量的估算”，用箭头标注乘法关系。
method: []
sources:
- 新版课本原页，详见本章sources.md
- 九套有效卷（SZ2022-12, SZ2023-18(3)）
```

### 本次只学

用样本中某类对象所占的比例，估计总体中的对应数量。

### 先认住

- 用样本估计总体：当样本具有良好代表性时，样本中某类对象所占的百分比，可以近似看作总体中该类对象所占的百分比。
- 估计总体中某类对象的数量：$\text{总体数量}\times\text{样本中该类对象的比例}$。
- 估计值不等于确切值，实际人数可能略有偏差，但能反映总体的大致水平。

### 容易错

- 把样本容量当成总体总数来乘，导致比例基数算错。
- 把估计出来的理论数值当成绝对确定的真实人数。

## 12.2a 扇形、条形与折线统计图

```yaml
id: MATH-7B-12-2a
title: 扇形、条形与折线统计图
weight: 一般
weight_note: 九套卷直接命中8次，但只来自5套卷，包含同一统计题的多问；均是常规读图、补图、比例与圆心角或图型选择，次数高但难度低，维持一般。
textbook: 七下 12.2，印刷p.160–165
prerequisites:
- id: MATH-7B-12-1a
  strength: soft
  reason: 统计图中的人数和百分比应对应同一批被调查对象。
evidence:
- 能根据条形图或扇形图中的信息计算总量或补全统计图。
- 能计算扇形统计图中各部分所对圆心角的度数（$360^\circ \times 百分比$）。
- 能根据数据特点选择合适的统计图（条形看数量多少、折线看变化趋势、扇形看百分比）。
figure: 可选·三种图对比：同一组数据显示为条形图、折线图、扇形图，标出各自特点。
method:
- MG16 数形结合
sources:
- 新版课本原页，详见本章sources.md
- 九套有效卷（GD2022-21(1), GZ2023-13, GZ2025-05, SZ2022-18, SZ2023-18）
```

### 本次只学

读懂条形图、折线图和扇形图，并在图表之间互算数量、百分比与圆心角。

### 先认住

- 条形统计图能清楚看出各项目的具体数量；折线统计图能清楚看出数量随时间变化的增减趋势；扇形统计图能直观反映各部分占总体的百分比。
- 扇形统计图中各部分所对圆心角的度数 $= 360^\circ \times \text{该部分所占百分比}$，所有扇形的圆心角度数之和等于 $360^\circ$。
- 双图联立求总量：当同一批数据同时给出条形图与扇形图时，利用某类别已知的具体数量除以它对应的百分比即可求出被调查的总数量。

### 数形结合

```bridge
mode: cards
式: 百分比 $\times360^\circ$
图: chart-pie-bar
形: 扇形的圆心角度数；条形的高低对应数量的大小
色: blue
结: 看条形的高度读具体频数，看扇形面积占比读百分比。
```

### 容易错

- 计算扇形圆心角时漏乘 $360^\circ$，误把百分比数值直接当作角度。
- 描述变化趋势时误选条形图，没有选用能连续反映走势的折线图。

## 12.2b 分组、频数与直方图

```yaml
id: MATH-7B-12-2b
title: 分组、频数与直方图
weight: 一般
weight_note: 九套卷直接命中1次，为频数分布直方图选择题；合讲组距、组数、频数、读图与补图，区间端点和纵轴频数含义容易误读。
textbook: 七下 12.2，印刷p.165–170
prerequisites:
- id: MATH-7B-12-2a
  strength: soft
  reason: 比较直方图与条形图，辨别连续分组与分类数据。
- id: MATH-7B-11-1a
  strength: soft
  reason: 用不等号读清各组区间端点是否包含在内。
evidence:
- 能从频数分布直方图中读出各组的频数或组距，并计算样本容量。
- 能根据各组频数判断哪一组数据最多或最少，并判断区间端点是否包含。
figure: 可选·直方图识图：标明横轴组距、纵轴频数以及小长方形高度表示频数。
method:
- MG16 数形结合
sources:
- 新版课本原页，详见本章sources.md
- 九套有效卷（GZ2024-05）
```

### 本次只学

理解频数分布直方图的组距与频数，分清各区间端点并准确读图。

### 先认住

- 把连续数据分组时，各组的两个端点之间的距离称为组距；落在各小组内的数据个数称为频数，各组频数之和等于抽样的数据总数。
- 频数分布直方图中，横轴表示数据分组，等距分组时纵轴表示频数，各小长方形的高反映该组频数的大小。
- 分组区间要认清端点不等号：课本通常采用“左闭右开”（如 $a \le x < b$），试卷题目若给出“左开右闭”（如 $a < x \le b$），必须严格按题目给出的区间判断边界值归属。

### 数形结合

```bridge
mode: cards
式: 小长方形的高 = 频数
图: chart-hist
形: 把数轴按组距等分切块，每个区间上方画出高度等于频数的矩形
色: blue
```

### 容易错

- 混淆直方图与条形图：条形图各条通常分开、表示离散分类，直方图各矩形紧挨、表示连续数值分组。
- 忽略区间端点的等号位置，数错边界数据所在的组别。

### 本次只学

在坐标系中把成对数据描成散点，用趋势线观察两个量的变化关系。

### 先认住

- 当研究两个量之间的关系时，可以用横轴表示一个量、纵轴表示另一个量，将成对的数据描成坐标平面上的点（散点）。
- 用一条尽可能靠近所有散点的线（直线或曲线）来描述两个量之间的关系，这种图叫作趋势图。
- 趋势图能直观反映两个量之间的大致变化趋势，并可据此估算或预测。

### 数形结合

```bridge
mode: cards
式: $(x,\,y)$
图: chart-scatter
形: 把两列数据配成点，描在坐标图上
色: blue
结: 观察散点的集中走向，用趋势线上点的坐标估算未知对应的数值。
```
