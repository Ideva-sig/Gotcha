# 课程内容格式（v3 样章格式）

> 状态：草案，2026-10-05 随物理第十三章样章建立。样章验收后再推广到其他章和其他学科。

## 和旧内容的关系

- `content-source/`（v1）：冻结，只作对照。物理 v1 是按旧版课本编的，不再沿用其结构。
- `content-v2/`：冻结为参考，不再往里加文档。
- `course/`：新的唯一维护源。网站最终从这里生成页面。

## 每章三个文件

```
course/{学科}/{章目录}/
  lesson.md      讲解：知识点正文 + 后台信息
  questions.md   题目：本章用到的全部题目，一题一个编号
  sources.md     来源与校对记录
```

学科级文件：

| 文件 | 内容 |
| --- | --- |
| `course/physics/textbook-sections.md` | 三册课本的章节编号索引，由课本目录生成 |
| `course/physics/kp-map.yml` | 知识点地图：全科知识点的编号、轻重、前置关系，见下一节 |
| `course/physics/exam-hits.tsv` | 真题逐题归类记录，一行一条：题号、知识点 |
| `course/physics/exam-stats.md` | 真题统计说明和汇总表，由脚本根据上一个文件生成 |

## 知识点地图 kp-map.yml（2026-10-05 用户确认）

一个文件覆盖三册全部 92 节，是全科的主干。**编号、轻重、前置关系都以它为准**，各章 `lesson.md` 里的同名字段必须和它一致。

每节一条：`section`（节编号）、`title`、`page`（课本印刷页）。普通节下面是 `kps` 列表；跨学科实践节不拆知识点，写 `type: 跨学科实践` 和一句 `task`（做什么）。

每个知识点的字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 节编号加一个小写字母，如 `PHY-9-13-1c` |
| `title` | 一个学习任务，约 6–12 字 |
| `weight` | 重点 / 一般 / 了解 |
| `exam_hits` / `exam_refs` | 统计范围内出现的次数和题号（如 `GZ2025-16(3)①`），必须与 `exam-hits.tsv` 一致 |
| `weight_note` | 定级理由，一句话 |
| `lab_exam` | 只在广州实验操作考试涉及时写：考哪道题、要做什么 |
| `prerequisites` | 1–4 条前置，写 `id`、`strength`（hard / soft）、`reason`。本科前置指向**知识点编号**；跨学科写 `CHEM-…`、`MATH-…` 自由编号 |

拆分原则：课本小标题太碎的合并；一节里同时有“概念”和“计算”的，把计算单独拆出；中考常考的综合辨析可以单独设点，放在它涉及的最后一节（如 `PHY-8A-03-4b` 判断物态变化、`PHY-9-17-4c` 判断电路故障）。思想方法导引的内容不进地图（数学也一样：思想方法不是知识点，融在讲法里，见“数学补充”）。

改地图或真题归类后运行：

```bash
/usr/bin/python3 scripts/check-kp-map.py --overview --write-stats
```

脚本检查编号格式、前置是否存在、有没有环、真题次数是否一致，并提示各章 `lesson.md` 与地图不一致的地方；`--write-stats` 重新生成 `exam-stats.md`。

## lesson.md

### 结构

1. 文件头（YAML）：章编号、课本出处、状态。
2. 本章导语（学生看）：一两句话说清这章学什么。
3. **本章前置自查**（学生看）：开始前要会的几件事，不会就去回看哪一节。
4. 若干知识点，每个知识点一个 `##` 标题。

### 每个知识点

标题下先放一个 `yaml` 代码块，这是**后台信息，不显示给学生**：

| 字段 | 含义 |
| --- | --- |
| `id` | 知识点编号，节编号加字母，如 `PHY-9-13-1c` |
| `weight` | 重点 / 一般 / 了解，见下方“轻重与篇幅”；可加 `weight_note` 说明理由 |
| `textbook` | 课本出处：册、节、印刷页 |
| `prerequisites` | 前置知识。每条写 `id`、`strength`（`hard` 不会就学不下去 / `soft` 会了更容易）、`reason`（一句话说明为什么需要） |
| `evidence` | 掌握证据：2–3 条“学会了能做到什么”，也是孩子自评的标准 |
| `figure` | 配图判断：需要 / 可选 / 不需要，以及图要帮学生看懂什么 |
| `sources` | 本知识点用到的来源代号，细节在 `sources.md` |

后面是**学生看的正文**，标题固定，没有内容的段落直接省略。**网站上显示的名字和这里不同**（任务式，2026-10-12 起；内容文件里仍写下面的原名，显示名只在 `src/lib/blockLabels.js` 一处改）：本次只学→本关任务，先认住→本关要点，数形结合→数形结合，走一遍→跟着闯一遍，容易错→踩坑提醒，练一练→闯一关，另外页面上的“过关进度”“通关自检”是网站生成的两个面板（原“怎样算掌握”“学完我能做到”）。

| 小标题 | 写什么 |
| --- | --- |
| 本次只学 | 一句话，说清这个知识点的学习任务 |
| 先认住 | 必要的定义、公式、规律，每条一行 |
| 破题钥匙 | 仅物理/化学、可选：现象→模型图→关系的卡片，见文末“物理补充”；放在“先认住”后 |
| 数形结合 | 仅数学、可选：数与形的对应，最多 3 行，见文末“数学补充” |
| 走一遍 | 一个完整的例子，按步骤写（只有“重点”知识点写） |
| 容易错 | 常见错误，短句 |
| 练一练 | 引用 `questions.md` 里的题目编号 |

**计算步骤的写法（2026-10-06 用户确认，“走一遍”和题目解析里的计算都这样写）**：

- 代入公式的数用蓝色：`\textcolor{#287fc4}{2}`。题目给的已知数、前一步算出再代入的数都算。
- 计算中约掉的单位划掉：`\cancel{\mathrm{kg}}`。复合单位写成 `\mathrm{J}/(\cancel{\mathrm{kg}}\cdot\cancel{^\circ\mathrm{C}})`。
- 每题（每个空）的最终答案加框：`\boxed{1.84\times10^{4}\ \mathrm{J}}`；中间步骤的结果不加框。
- 不是计算的推理步骤照常写文字，不加这些标记。
- 蓝色只作辅助，不靠颜色也要看得懂；方框和删除线去掉颜色也看得清。

**写作规则**：
- 自绘示意图（SVG）的文字必须放在空白处或纯色底上，不能让线条、箭头、边框穿过或贴住文字。标注放不下时，缩短文字或改用引线，不要硬塞。
- 引用题目时，编号单独占一行，写成“- `Q-...`”；只引用某一问时在后面写“第（1）问”。说明文字另起一行，不和编号写在同一行。
- 学生正文里不出现来源说明、审查标签、维护说明。
- 公式一律写成 `$...$` 的 LaTeX，比如 `$Q_{\text{吸}}=cm(t-t_0)$`。
- 和课本冲突时以课本为准，冲突记录写进 `sources.md`。
- 课本没有、但真题解析常用的内容，经项目负责人同意后可以加入“先认住”，开头写“**补充**（课本没有讲，做真题时常用）：”，并在 `sources.md` 记录决定。目前有：串联总电阻 $R=R_1+R_2$（17.4a）；刻度尺估读到分度值的下一位（8A 1.1a）、停表读法（8A 1.1b）、匀速直线运动的 s-t 和 v-t 图像（8A 1.3c）、天平调平“指针偏哪边，平衡螺母向反方向调”（8A 6.1b）（后四项 2026-10-06 用户同意）；功率 $P=Fv$（8B 11.2a）、轮轴判断“轮带动轴时动力臂较长”（8B 12.1c）（2026-10-07 用户同意）。

### 轻重与篇幅（2026-10-05 定）

孩子主要在 iPad 上学，自控时间有限。所以**内容量跟着考点轻重走，题目少而准**，不追求题量储备。

每个知识点在后台写 `weight`，依据是近几年广州、广东、深圳中考卷里的出现次数和分值，统计写进 `sources.md`：

| weight | 什么样的知识点 | 先认住 | 走一遍 | 容易错 | 练一练 |
| --- | --- | --- | --- | --- | --- |
| 重点 | 几乎每年考、分值高，或是常见陷阱 | ≤ 4 条 | 1 个 | ≤ 3 条 | 1–2 道（“走一遍”本身是判断练习时，1 道即可） |
| 一般 | 常考但容易得分 | ≤ 3 条 | 不写 | ≤ 2 条 | 1 道 |
| 了解 | 很少直接考 | ≤ 3 条 | 不写 | 不写 | 0 道 |

- “了解”级可以省略“本次只学”，`evidence` 可以只写 1 条。
- 一章的题目一般在 10 道以内。优先用真题，真题不合适再用课本习题。
- 思想方法导引的内容暂不进入物理讲义；数学的用法见文末“数学补充”。
- 学生版标题旁显示“重点 / 一般 / 了解”，让孩子知道时间该花在哪。

### 示意图规范（2026-10-05 定，参考 WeduLab 目录页的动态示意图）

> 2026-10-06 用户决定：除已画好的 SVG 外，示意图在各学科正文全部定稿后用 gpt-image-2.5 统一生成，见 `AGENTS.md`。下面的规范仍适用于已有 SVG 和生成图的核对（配色、文字不被压住、一张图只讲一个道理）。2026-10-07 修订：几何必须精确的图（光路、力、力臂、滑轮、刻度、电路）改为手写静态 SVG，只有场景图用生图，见 `AGENTS.md`。手写 SVG 可以不加动画，但仍要满足下面的命名、`title`/`desc`、文字不被压住等要求。

物理、化学的原理图、实验图统一用**轻量动态 SVG**：网页和 iPad 上会动，停住时是一张完整的静态图。

1. **一张图只讲一个道理**。画布宽 320–640，元素少，线条 1.6–2.6px，颜色不超过三种（取自网站配色：蓝 `#287fc4`、珊瑚红 `#c9554d`、黄 `#bf8d08`、绿 `#197a60`，线框 `#52626a`）。
2. **静态画面必须完整、正确**：任何时刻暂停下来，都是一张能单独看懂的图。动画只能叠加在完整的底图上，比如流动的虚线、明暗变化、小幅晃动；不能靠动画才把内容“画出来”。“减少动态效果”时画面固定在第 0 秒，所以第 0 秒应该是最能说明问题的状态（如活塞已压下、瓶塞已跳起）。
3. **动画只表现过程和方向**：电流、热量的流向用沿线流动的虚线（`stroke-dashoffset`），发光、发热用明暗变化（`opacity`），分子运动用小幅位移（`animateTransform`）。用 SVG 自带的 `<animate>` 系列，不用脚本，不用 GIF。
4. **图里的文字越少越好**：只留物体名称、坐标轴这类短标签（一般不超过 4 个字），解释写在正文里。**文字本身不能参与动画。**
5. **文字不能被任何图形压住**，在动画的每一帧都要满足（检查脚本每 0.25 秒抽一帧）。
6. **命名唯一**：SVG 会直接嵌进网页，`<style>` 里的类名和 `id` 必须加上图的前缀（如 `wd-lb`、`work-demos-t`），避免不同的图互相影响。
7. 每张图写 `<title>` 和 `<desc>`，`desc` 说明静态画面和动画各表现了什么。
8. 系统开启“减少动态效果”时，网页也会把动画停在第 0 秒。

#### 实物感画法（2026-10-25 定稿，学 WeduLab 目录页的实验图）

滑轮、称重法两张试画经用户确认后定稿。新画的图照此画；已有的物理图里画了实物（器材、物体、液体、支架）的按此重画，纯图像、波形、光路、电路图、流程图不改。学的是画法，不照搬它的具体图形。

重画时：
- 几何不变（坐标、尺寸、文字位置照旧），只改线宽、填充和支架画法。
- 原图里已有含义的颜色（数绳子段数的标色、力臂、指针、运动方向）保持不变；只有不带含义的绳子改成灰色细线。
- 器材和电路混画的图，电路符号部分仍按课本黑色画，只给器材部分上浅色、改线宽。
- 动态图的浅色填充是静态的，不改动画对象和时间，第 0 秒仍是完整的图。

1. **按物体上浅色**：用同一套讲义色的淡色填充，让物体一眼能分开，不算新增颜色（上面第 1 条的“三种颜色”仍按色相算）。
   - 液体：蓝 `#287fc4`，不透明度 0.12（即 `#e3f1fa`）。
   - 被提起、被称量的物体（重物、砝码、货物）：黄 `#bf8d08`，不透明度 0.18。
   - 仪器和机械本体（测力计外壳、滑轮、支架）：线框灰 `#52626a`，不透明度 0.08。
   - 白色只留给“纸面”和读数区（如测力计刻度板）。
2. **线条分三档粗细**：
   - 主角轮廓（滑轮、物体、测力计外壳、容器）2.4px。
   - 绳子、挂钩、支架、刻度、引线 1.6px。
   - 看不见的线、轨迹、辅助线用 1.6px 虚线（`5 4`）。
   - 力的箭头 2.6px，不变。
   - 绳子一律灰色细线，蓝色只留给力。
3. **点到为止的场景**：
   - 天花板、支架画一条粗线加一排短斜线（1.4px，间距 10 左右），表示“固定在这里”。
   - 地面、桌面画一条线，不画背景。
   - 不加方格纸底纹，讲义区保持白纸。
4. **颜色只表达含义**：
   - 力用蓝。
   - 运动方向、读数指针用珊瑚红。
   - 仪器本体保持中性灰，不按仪器种类另配颜色。
   - 电路图仍按课本黑色符号画。
5. **淡光晕**：只给正在发光、发热的东西（亮着的灯、火焰、太阳）。圆形渐变，不透明度不超过 0.25，不能盖住文字。
6. **文字**：写在白底或上面这些淡色上，对比度不低于 4.5:1；检查脚本照样要过。

### 前置知识的写法

- 前置指向**知识点编号**（如 `PHY-9-13-1a`、`PHY-8A-06-4a`），从 `kp-map.yml` 里抄，不要自己另写；该知识点的章节还没编写也照样引用。
- 跨学科的前置写成 `CHEM-9A-U3`、`MATH-比例` 这样的自由编号（编号里不带空格，名称写进 `reason`），一般标 `soft`。
- 只写真正用得上的前置，每个知识点一般 1–4 条。

## questions.md

文件分两部分：前面是讲义用题，按知识点顺序排；后面是“备选”，已核对但不进入讲义、不再维护，换题时从这里挑。

每道题一个 `###` 标题，标题就是题目编号，下面先放一个 `yaml` 代码块：

| 字段 | 含义 |
| --- | --- |
| `id` | 题目编号，见下方规则 |
| `category` | `课本习题` / `真题` / `导引例题` |
| `source` | 出处，精确到题号 |
| `source_quality` | `原卷` / `平台导出件，待原卷核对` / `课本原文` / `导引原文` |
| `kp` | 主要对应的知识点；多小问的题，在每个小问里单独写 |
| `do` | 只用到部分小问时写明，如“本章只做第（2）问”；其余小问的去向写在 `other_parts` |
| `type` | `选择` / `选填` / `填空` / `计算` / `简答` / `作图` |
| `grading` | `自动`（只限选择题和有固定选项的选填） / `自评` |
| `answer_by` | 答案和解析出处：`原卷解析` / `导引原解` / `本项目编写，待复核` / `本项目编写，已复核` |
| `review` | 错因 → 回看哪里，就是错题本的“快速定位” |

然后依次是 **题干**、**答案**、**解析**，解析按“一步一行”写。

**题目编号**：
- 课本习题：`Q-PHY-TB9-13.1-3` 表示九年级课本 13.1 节“练习与应用”第 3 题；`13R` 表示本章“复习与提高”。
- 真题：`Q-PHY-GZ2025-16-3a` 表示 2025 广州卷第 16 题第（3）问第①小问。地区代码：`GZ` 广州、`GD` 广东省、`SZ` 深圳。
- 多选题、作图题暂不进入自动判分；多选题在网站支持多选之前不收。
- **作图题**（2026-10-07 用户确认）：真题作图题有原卷答案图的可以收，`type: 作图`、`grading: 自评`，答案栏放原卷答案图（如 g9-19 的 GD2023-17）；课本习题仍只收纯文字、不看图也能答的。
- 导引例题：`Q-PHY-MG34-E1` 表示思想方法导引第 34 节例 1。

**错因标签**只用这 6 个：`概念`、`公式`、`单位`、`计算`、`审题`、`前置`。孩子自评做错时选一个，错题本就按 `review` 里的对应关系，把她带回该看的知识点或前置知识。

**题目政策**：
- 现阶段只收课本习题、真题、导引例题，**不自编题**。改编题一律不收。
- 课本习题可以作为“练一练”使用（2026-10-05 用户确认）。课本习题没有官方答案，答案和解析由本项目编写，必须标 `本项目编写，待复核`，家长复核后改为 `本项目编写，已复核`（2026-10-06 家长已复核九全、八上讲义里用到的全部课本习题答案）。

## sources.md

只记四件事，不写成审计报告：

1. 用了哪些来源，精确到页、行或题号；
2. 来源之间的冲突，以及取哪一方；
3. 看过但没采用的内容，以及原因；
4. 还没解决的问题。

## 网站数据接口（v3 JSON，2026-10-05 定，草案）

网站不直接读 Markdown，由导出脚本把 `course/` 转成 JSON：

```bash
/usr/bin/python3 scripts/export-course-json.py physics
```

输出到 `output/app-data/physics/`。导出时不做任何内容改写，只做结构转换；学生看不到的后台字段（来源、`weight_note`、`answer_by` 等）照样导出，由前端决定显示与否。

```
output/app-data/physics/

- 需要点破时，在“走一遍”或解析里写**一句**大白话，放在用到它的那一步，如“画出抛物线，$y>0$ 的部分一眼就能看出来。”一个知识点最多一句。
- 后台 `yaml` 里加 `method` 字段，记这个知识点用了导引哪一章的思路（如 `method: [MG16 数形结合]`），学生看不到，用于检查全书覆盖面。

### 公式和推导的写法

计算步骤沿用上面的规则（代入的数用蓝色、最终答案加框、中间结果不框）。数学另加：

- **颜色有固定含义**，同一个知识点里不变：
  - 蓝 `#287fc4`：已知条件、代入的数、正在使用的公式；
  - 绿 `#197a60`：由前面推出的结论（不是最终答案的那种）；
  - 黄 `#bf8d08`：这一步正要处理的项（要配方的、要移项的、要约去的）；
  - 珊瑚红 `#c9554d`：错误做法、要警惕的地方，只在“容易错”和对比写法里用。
- **数形对应时颜色改为“一物一色”**：同一个量在式子里和图里用同一种颜色（如 $y=\textcolor{#287fc4}{a}(x-\textcolor{#c9554d}{h})^2+\textcolor{#197a60}{k}$，图里开口、对称轴、顶点分别用这三种颜色）。这时颜色不再表示上一条的含义，两种用法不在同一个公式块里混用。
- 下括号注释：`\underbrace{x^2-4x+4}_{\text{完全平方}}`，注释不超过 6 个字。
- 约去、抵消的项用 `\cancel{}` 划掉。
- 对比写法：错误一行整行红色，后面紧跟正确一行；只在“容易错”里用。
- 黑白下颜色看不出来，所以颜色只作辅助，单看黑白也必须能读懂。

### 配图（数学）

数学配图分三类，`figure` 字段写明类别：

1. **图解步骤图**（首选，2026-10-07 用户认可的样式，参考 omath 的 $(a-b)^2$ 面积图解和多项式乘法连线图）：把式子和图形画在同一张宽图里，按步骤从左到右（或从上到下）排开，每一步一个小图；或者直接在式子上画同色弧形箭头标出运算关系。式子里的字母和图里对应的边、点、角**同色**。静止时所有步骤都在。
   - 网页上可做成**分步动画**（2026-10-07 用户认可 omath 的立方和视频：图形每动一步，式子同步出现对应的一项，颜色一一对应）：打开时显示完整的最终状态；按“播放”从头演示，图形块移动、拼接，式子按步骤同步出现；可以单步前进、后退。这类图允许“靠动画把内容画出来”，因为默认显示的是完整状态；“减少动态效果”时也显示完整状态。
   - 立体或特别复杂的过程（如立方和、投影与视图）可以改用 Manim 视频，文件放在章目录 `figures/` 下，同时配一张最终状态的静态图。
2. **几何图**：课本、真题里的几何图形，坐标计算出来再画（不手估）。规范：
   - 题目给的线用实线，辅助线用虚线；
   - 点名用课本的写法（大写字母），标在图形外侧空白处，不压线；
   - 直角画小方块，相等的角画同数量的小弧，相等的线段画同数量的短刻痕；
   - 底图线框 `#52626a`，当前要看的元素用一种强调色，一张图强调色不超过两种。
   - 题图仍用原卷截图，不重画。
3. **可拖动的图**（只给“重点”知识点，2026-10-07 用户决定）：孩子能拖滑块或拖点，图和旁边的式子同步变化（如拖动 $a$、$h$、$k$ 看抛物线怎么变；圆周角顶点沿圆周拖动，角度不变）。这类图由网站里少量通用组件实现，讲义里只写组件名和参数；每个可拖动的图必须同时有一张静态 SVG（初始状态），“减少动态效果”时显示它。

三类图都遵守上面的示意图规范（第 0 秒完整、文字不参与动画、文字不被压住、命名唯一）。

**讲义里怎样放图（2026-10-08 定，画图和网站按同一约定）**：

- 静态图、分步图：照常写 `![说明](figures/xxx.svg)`，放在它说明的那一段后面。
- **分步图的 SVG 写法**：每一步的元素包在 `<g data-step="1">`、`<g data-step="2">`…… 里，按顺序编号；不属于任何一步的底图（坐标轴、网格）放在这些组外面。SVG 文件本身不写动画，所有步骤都可见，也就是“完整的最终状态”。网站识别到 `data-step` 就加上“播放 / 上一步 / 下一步”，播放时从只有底图开始，一步步显示；“减少动态效果”时不播放。
- **可拖动的图**写成一个代码块，网站换成对应组件；代码块后面紧跟一张静态图（初始状态），网站显示组件时隐藏这张图：

  ````
  ```widget
  type: parabola-explorer
  a: {min: -2, max: 2, step: 0.5, value: -0.5, skip: 0}
  h: {min: -3, max: 3, step: 0.5, value: 0}
  k: {min: -3, max: 3, step: 0.5, value: 0}
  ghost: "y=-1/2(x+1)^2-1"   # 可选：灰色参照曲线
  ```
  ![初始状态：y=-1/2 x^2，顶点在原点](figures/parabola-explorer-26-2b.svg)
  ````

  组件目前五个。参数用单行键值和花括号、方括号；不支持缩进式多行参数、YAML 引用或表达式执行。代码块后必须紧跟静态 SVG，中间不要插入文字。加载失败、减少动态效果时显示静态图。

  - `parabola-explorer`：`a`、`h`、`k` 均必填，格式见上例。`min`、`max`、`step`、`value` 为数字，初值必须落在步长网格上；`skip` 可为一个数或数组，`a` 必须排除 0。滑块只经过合法值，不会停在 0。`ghost` 可写 `"y=-1/2(x+1)^2-1"` 这样的顶点式，推荐明确写 `ghost: {a: -0.5, h: -1, k: -1}`。可选 `points: [{x: -1, y: -1, label: P}, {x: 1, y: -3, label: Q}]`，提供 `y` 时是固定参照点；省略 `y` 时按当前曲线计算纵坐标，如 `points: [{x: 3}, {x: 6}, {x: 9}]`。`label` 可省略，默认显示坐标。超出视窗的点不显示。当前坐标视窗为 x∈[-9,9]、y∈[-8,8]，请让初始图与参数、视窗一致。
  - `circle-angle`：角度从圆的右端起算，逆时针为正；A 固定，B、C 可拖。C 被限制在小弧 AB 的另一侧，不与 A、B 重合。圆心角取不超过 180° 的角，B 距直径位置不足 3° 时吸附到直径。圆心角初值 100°、圆周角 50°，完整写法如下：

    ```widget
    type: circle-angle
    A: {angle: 0, draggable: false}
    B: {angle: 100, draggable: true}
    C: {angle: 230, draggable: true, range: opposite-arc}
    gap: 8
    ```

    `gap` 为端点安全间距（角度，默认 8，允许 2–30）；B 与 A 至少相隔该角度，C 与弧端点也保留该间距。`B.draggable`、`C.draggable` 可设为 `false`。兼容现有讲义的 `center: [0, 0]`、`radius: 1`（圆心与半径，画面自动缩放）；B 可用 `min: 0, max: 180, minExclusive: true` 限定极角范围，排除下端点时留出 `gap`；C 的 `arc: opposite, excludeEndpoints: true` 等同于 `range: opposite-arc`，始终排除弧端点。圆周角用绿，圆心角用蓝。角度读数四舍五入到整数，因此非偶数圆心角的两项读数可能有 1° 的舍入差。
  - `line-explorer`：一次函数 $y=kx+b$。`k`、`b` 均必填，参数含 `min`、`max`、`step`、`value`，初值必须落在步长网格上；`k` 可选配置 `skip`（讲义可能跳过 0）。可选 `points: [{x: 1}, {x: 0}]` 按当前直线标出横坐标为 $x$ 的点（省略 $y$），超出视窗的点不显示。当前坐标视窗为 x∈[-6,6]、y∈[-6,6]，请让初始图与参数、视窗一致。完整写法如下：

    ```widget
    type: line-explorer
    k: {min: -3, max: 3, step: 0.5, value: 2}
    b: {min: -4, max: 4, step: 1, value: -1}
    points: [{x: 1}, {x: 0}]   # 可选
    ```

  - `inverse-explorer`：反比例函数 $y=\dfrac{k}{x}$。`k` 必填，参数含 `min`、`max`、`step`、`value`、`skip`，初值必须落在步长网格上且 `skip` 必须排除 0。可选 `point: {x: 2, min: -6, max: 6, step: 0.5, skip: 0}` 在曲线上标出随 $x$ 滑动的点 $P(x,\,k/x)$，$x$ 同样必须跳过 0。双曲线两支分开绘制，不跨越 $x=0$ 连线。当前坐标视窗为 x∈[-6,6]、y∈[-6,6]，请让初始图与参数、视窗一致。完整写法如下：

    ```widget
    type: inverse-explorer
    k: {min: -6, max: 6, step: 1, value: 3, skip: 0}
    point: {x: 2, min: -6, max: 6, step: 0.5, skip: 0}   # 可选
    ```
  - `number-line`：数轴，两种用法。`mode: abs` 拖动一个点，同时显示它和相反数的位置及绝对值（`min`、`max` 必须关于原点对称）；`mode: ray` 选不等号（大于 / 大于等于 / 小于 / 小于等于）并拖动端点，空心圆圈或实心点加射线表示解集，可选 `rel: ">="` 设初始不等号。都需要 `min`、`max`、`value`，可选 `step`（默认 1，`abs` 常用 0.5）。完整写法如下：

    ```widget
    type: number-line
    mode: ray
    min: -5
    max: 5
    value: 2
    rel: ">"
    ```
- 颜色：讲义和 SVG 里写项目四色的十六进制值；网站在深色模式下把这四个值换成调亮后的颜色（KaTeX 公式里的 `\textcolor` 也一样），讲义不用管。
