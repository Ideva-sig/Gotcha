# 初中化学（九上）公式与结论速查

按九年级上册七个单元整理，做题时随手查。方程式一律要配平、写条件、标气体或沉淀符号。

---

## 一、 化学用语与化合价

化学式、离子符号、化合价是“化学语言”，写错一个小数字整题就丢分。

### 01. 常见元素与原子团的化合价

- **公式与结论**：
  一价钾钠银氢铵（$\ce{K}$、$\ce{Na}$、$\ce{Ag}$、$\ce{H}$、$\ce{NH4}$ 显 $+1$）；二价钙镁钡锌铜（显 $+2$）；铝显 $+3$；铁有 $+2$（亚铁）、$+3$（铁）；
  负一硝酸氢氧氯（$\ce{NO3}$、$\ce{OH}$、$\ce{Cl}$ 显 $-1$）；负二硫酸碳酸氧（$\ce{SO4}$、$\ce{CO3}$、$\ce{O}$ 显 $-2$）。
- **符号含义**：化合价标在元素或原子团的正上方，写成“$+1$”“$-2$”，符号在前、数字在后。
- **适用条件**：化合物里的常见价态；单质里元素化合价为 $0$。
- **中考避坑要点**：
  1. 化合价（正上方，如 $\overset{+2}{\ce{Mg}}$）和离子电荷（右上角，如 $\ce{Mg^2+}$）写法不同，数字、符号的顺序也相反。
  2. 氧元素在氧化物里显 $-2$，但在单质 $\ce{O2}$ 里是 $0$。

### 02. 化合价代数和为零

- **公式与结论**：化合物中，各元素“原子个数 $\times$ 化合价”之和为 $0$。例：$\ce{Fe2O3}$ 中设铁为 $x$，$2x + 3\times(-2) = 0$，得 $x = +3$。
- **符号含义**：$x$ 为待求元素的化合价。
- **适用条件**：所有化合物；原子团里各元素化合价之和等于原子团的电荷。
- **中考避坑要点**：
  1. 先列式再算，别心算漏乘原子个数。
  2. 写化学式时正价在前负价在后，求两价绝对值的最小公倍数，再化成最简整数比并验算。

### 03. 化学式与符号周围数字的含义

- **公式与结论**：
  $2\ce{H2O}$：前面的 $2$ 表示 2 个水分子；$\ce{H2O}$ 中的 $2$ 表示 1 个水分子中有 2 个氢原子；$\ce{Mg^2+}$ 的 $2+$ 表示 1 个镁离子带 2 个单位正电荷；$\overset{+2}{\ce{Mg}}\ce{O}$ 的 $+2$ 表示氧化镁中镁元素显 $+2$ 价。
- **符号含义**：前面的数字表示粒子个数；右下角表示一个粒子里的原子个数；右上角表示离子电荷；正上方表示化合价。
- **适用条件**：读写化学符号和化学式。
- **中考避坑要点**：
  1. 元素符号前面的数字只表示原子个数，此时不能再谈“元素”（元素只讲种类，不讲个数）。
  2. 离子符号的数字在前、正负号在后（$\ce{Mg^2+}$），化合价则是符号在前、数字在后（$+2$）。

## 二、 物质构成与元素周期表

从分子、原子、离子到元素，建立“微观看物质”的思路。

### 04. 原子的构成与数量关系

- **公式与结论**：原子序数 $=$ 核电荷数 $=$ 质子数 $=$ 核外电子数；相对原子质量 $\approx$ 质子数 $+$ 中子数。
- **符号含义**：原子核由质子和中子构成（氢原子核内没有中子）；质子带正电，中子不带电，电子带负电；原子整体不显电性。
- **适用条件**：原子。离子的质子数不等于电子数。
- **中考避坑要点**：
  1. 原子的质量几乎全集中在原子核上，电子的质量可以忽略。
  2. 判断“是原子还是离子”：看质子数和电子数是否相等。

### 05. 核外电子排布与离子的形成

- **公式与结论**：电子分层排布，第一层最多 $2$ 个，第二层最多 $8$ 个，最外层最多 $8$ 个（只有一层时最多 $2$ 个）。最外层电子数 $<4$ 易失电子，形成阳离子；$>4$ 易得电子，形成阴离子；最外层 $8$ 个（氦为 $2$ 个）为相对稳定结构。
- **符号含义**：原子结构示意图里圆圈内数字是质子数，弧线是电子层，弧线上数字是该层电子数。
- **适用条件**：前 $20$ 号元素。
- **中考避坑要点**：
  1. 失去电子后，质子数不变、电子数减少，所以阳离子的质子数大于电子数。
  2. 元素的化学性质主要由最外层电子数决定；最外层电子数相同，化学性质相似（氦例外）。

### 06. 元素周期表单元格的读法

- **公式与结论**：左上角是原子序数，右上角是元素符号，中间是元素名称，下方是相对原子质量。原子序数 $=$ 质子数 $=$ 核外电子数（原子）。
- **符号含义**：相对原子质量是相对值，单位为“$1$”，一般不写出。
- **适用条件**：读周期表单元格；同一横行为一个周期（电子层数相同），同一纵列为一族（最外层电子数一般相同）。
- **中考避坑要点**：
  1. 相对原子质量不是原子的真实质量，也不是质子数加中子数的精确值。
  2. 元素名称带“钅”旁的是金属元素，带“石”“气”“氵”的一般是非金属元素；汞是例外的液态金属。

## 三、 反应与方程式

本册要求会写、会配平、会读的方程式。

### 07. 质量守恒定律与配平

- **公式与结论**：参加反应的各物质的质量总和 $=$ 反应后生成的各物质的质量总和。原因：化学反应前后，原子的种类、数目、质量都不变。
- **符号含义**：“六个不变”：原子种类、原子数目、原子质量、元素种类、元素质量、物质总质量；“两个一定变”：分子种类、物质种类；“两个可能变”：分子数目、元素化合价。
- **适用条件**：一切化学变化。物理变化不能用质量守恒定律解释。
- **中考避坑要点**：
  1. 有气体参加或生成的反应，要在密闭容器里验证，否则天平不平。
  2. 守恒的是“质量”，不一定是“体积”或“分子个数”。
  3. 配平只能改化学计量数（前面的系数），不能改化学式右下角的小数字。

### 08. 书写化学方程式的步骤

- **公式与结论**：写（左写反应物、右写生成物，中间短线）$\rightarrow$ 配（配平）$\rightarrow$ 注（注明条件和状态）$\rightarrow$ 等（短线改等号）。例：$\ce{4P + 5O2 ->[\text{点燃}] 2P2O5}$。
- **符号含义**：反应物是固体而生成物有气体，气体后标 $\uparrow$；溶液中的反应生成沉淀，沉淀后标 $\downarrow$。反应物里已有气体（或固体）时，生成物的气体（或沉淀）不再标。
- **适用条件**：以客观事实为基础，不能凭空捏造不存在的反应。
- **中考避坑要点**：
  1. 先写对化学式，再谈配平；化学式错了，后面全错。
  2. 条件“点燃”“加热”“高温”“通电”不能写成“燃烧”；“$\Delta$”表示加热。

### 09. 本册必会的化学方程式

- **公式与结论**：
  - 红磷燃烧：$\ce{4P + 5O2 ->[\text{点燃}] 2P2O5}$
  - 硫燃烧：$\ce{S + O2 ->[\text{点燃}] SO2}$
  - 碳充分燃烧：$\ce{C + O2 ->[\text{点燃}] CO2}$；不充分：$\ce{2C + O2 ->[\text{点燃}] 2CO}$
  - 氢气燃烧：$\ce{2H2 + O2 ->[\text{点燃}] 2H2O}$
  - 电解水：$\ce{2H2O ->[\text{通电}] 2H2 ^ + O2 ^}$
  - 加热高锰酸钾：$\ce{2KMnO4 ->[\Delta] K2MnO4 + MnO2 + O2 ^}$
  - 过氧化氢分解：$\ce{2H2O2 ->[\text{MnO}_2] 2H2O + O2 ^}$
  - 实验室制二氧化碳：$\ce{CaCO3 + 2HCl -> CaCl2 + H2O + CO2 ^}$
  - 检验二氧化碳：$\ce{Ca(OH)2 + CO2 -> CaCO3 v + H2O}$
  - 二氧化碳与水：$\ce{CO2 + H2O -> H2CO3}$；碳酸分解：$\ce{H2CO3 -> H2O + CO2 ^}$
  - 碳还原氧化铜：$\ce{2CuO + C ->[\text{高温}] 2Cu + CO2 ^}$
  - 甲烷燃烧：$\ce{CH4 + 2O2 ->[\text{点燃}] CO2 + 2H2O}$
- **符号含义**：过氧化氢分解里二氧化锰是催化剂，写在箭头上方，不是反应物。
- **适用条件**：以课本和课堂要求为准；超出本册的方程式遇到时题目会给出。
- **中考避坑要点**：
  1. 实验室制氧用高锰酸钾和过氧化氢，本册课本里没有氯酸钾制氧。
  2. 实验室制二氧化碳不用稀硫酸（生成微溶的硫酸钙裹住石灰石），也不用浓盐酸（易挥发，气体不纯）。

### 10. 四种基本反应类型（本册涉及前两种）

- **公式与结论**：化合反应：多变一（$\text{A} + \text{B} \rightarrow \text{AB}$）；分解反应：一变多（$\text{AB} \rightarrow \text{A} + \text{B}$）。
- **符号含义**：氧化反应：物质与氧气发生的反应；有氧气参加的反应一定是氧化反应，但不一定是化合反应。
- **适用条件**：判断反应类型时先看反应物和生成物的种类数。
- **中考避坑要点**：
  1. 石蜡在氧气中燃烧生成二氧化碳和水，是氧化反应，但不是化合反应（生成物有两种）。
  2. 化合反应的生成物只有一种；生成物只有一种的反应不一定要有氧气参加。

## 四、 计算

本册计算只有两类：依据化学式算、依据化学方程式算。

### 11. 依据化学式的三个计算

- **公式与结论**：
  相对分子质量 $M_{\text{r}} = \sum (\text{相对原子质量} \times \text{原子个数})$；
  元素质量比 $=$ 各元素（相对原子质量 $\times$ 原子个数）之比；
  $$\omega(\text{元素}) = \frac{\text{该元素的相对原子质量} \times \text{原子个数}}{\text{相对分子质量}} \times 100\%$$
  某元素的质量 $=$ 化合物质量 $\times$ 该元素的质量分数。
- **符号含义**：$\omega$ 为质量分数；相对原子质量是相对值，单位为“$1$”。
- **适用条件**：已知化学式的纯净物。
- **中考避坑要点**：
  1. 元素质量比用相对原子质量乘原子个数，不是原子个数比。
  2. 带括号的原子团，括号外的数字要乘到括号里每一个原子上，如 $\ce{Ca(OH)2}$ 有 $2$ 个氧原子、$2$ 个氢原子。
  3. 结果取质量分数时，别忘了乘 $100\%$。

### 12. 依据化学方程式的计算

- **公式与结论**：质量比 $=$ 化学计量数 $\times$ 相对分子质量（相对原子质量）之比，列比例式求解。
  步骤：设（设未知量，不带单位）$\rightarrow$ 写（写出配平的方程式）$\rightarrow$ 找（找出相关物质的质量比和已知量）$\rightarrow$ 列（列比例式）$\rightarrow$ 答。
- **符号含义**：已知量必须是纯净物的质量，且带单位代入。
- **适用条件**：反应完全；不纯物要先换算为纯净物质量。
- **中考避坑要点**：
  1. 方程式没配平，质量比就是错的。
  2. 只有纯净物的质量能直接代入；混合物的质量、体积都不能直接代入。
  3. 质量守恒可以先算气体的质量：气体质量 $=$ 反应前总质量 $-$ 反应后剩余物总质量。

## 五、 气体制取与检验

固体加热型、固液常温型两套发生装置，加上收集与检验，是实验题的固定套路。

### 13. 氧气与二氧化碳的实验室制取

- **公式与结论**：见下表。

| | 氧气（高锰酸钾） | 氧气（过氧化氢） | 二氧化碳 |
| --- | --- | --- | --- |
| 药品 | 高锰酸钾 | 过氧化氢溶液、二氧化锰 | 大理石或石灰石、稀盐酸 |
| 发生装置 | 固体加热型 | 固液常温型 | 固液常温型 |
| 收集 | 排水法或向上排空气法 | 排水法或向上排空气法 | 向上排空气法 |
| 检验 | 带火星木条复燃 | 带火星木条复燃 | 澄清石灰水变浑浊 |
| 验满 | 木条放瓶口复燃 | 木条放瓶口复燃 | 燃着木条放瓶口熄灭 |

- **符号含义**：选发生装置看反应物状态和反应条件；选收集装置看气体密度和溶解性。
- **适用条件**：初中常见气体。二氧化碳能溶于水且密度比空气大，不用排水法，要用向上排空气法。
- **中考避坑要点**：
  1. 加热高锰酸钾时试管口要放一团棉花（防止粉末进入导管），试管口略向下倾斜。
  2. 用排水法收集氧气，要等气泡连续均匀冒出再收集，实验结束先移出导管再熄灭酒精灯。
  3. 长颈漏斗的下端必须伸入液面以下（液封），否则气体会从漏斗跑掉。
  4. 验满放在瓶口，检验伸进瓶内，不要混淆。

### 14. 气体的鉴别

- **公式与结论**：氧气：带火星木条复燃；二氧化碳：通入澄清石灰水变浑浊；氢气：点燃，淡蓝色火焰，烧杯壁有水雾；一氧化碳：点燃，蓝色火焰，生成物使澄清石灰水变浑浊；氮气：不燃烧也不支持燃烧，燃着的木条放入会熄灭。
- **符号含义**：不同气体的特征反应。
- **适用条件**：用燃着的木条鉴别空气、氧气、二氧化碳：燃烧更旺是氧气，无明显变化是空气，熄灭是二氧化碳。
- **中考避坑要点**：
  1. 使燃着的木条熄灭的气体不一定是二氧化碳，也可能是氮气，要用澄清石灰水确认。
  2. 氢气、一氧化碳等可燃性气体点燃前必须验纯。

## 六、 性质与现象

描述实验现象时，只写“看到”的，不写生成物名称。

### 15. 物质在氧气中燃烧的现象

- **公式与结论**：见下表。

| 物质 | 现象 | 生成物 |
| --- | --- | --- |
| 木炭 | 空气中红热；氧气中发白光、放热 | 二氧化碳（使澄清石灰水变浑浊） |
| 硫 | 空气中淡蓝色火焰；氧气中明亮的蓝紫色火焰，有刺激性气味 | 二氧化硫 |
| 红磷 | 产生大量白烟、放热 | 五氧化二磷 |
| 铁丝 | 空气中不燃烧；氧气中剧烈燃烧、火星四射、生成黑色固体 | 四氧化三铁 |
| 镁条 | 发出耀眼白光，生成白色固体 | 氧化镁 |

- **符号含义**：氧气能支持燃烧，具有助燃性，不具有可燃性。
- **适用条件**：描述现象时区分“烟”（固体小颗粒）和“雾”（小液滴）。
- **中考避坑要点**：
  1. 磷燃烧是“白烟”，不是“白雾”。
  2. 铁丝在氧气中燃烧，集气瓶底要放少量水或细沙，防止高温熔融物溅落炸裂瓶底；硫燃烧，瓶底放水是为了吸收二氧化硫，防止污染空气。
  3. 描述现象不能出现生成物的名称，如不能写“生成二氧化硫”。

### 16. 碳单质与碳的氧化物

- **公式与结论**：
  - 金刚石（硬度大）、石墨（软、能导电）、$\ce{C60}$ 的物理性质差异大，原因是碳原子排列方式不同；活性炭、木炭有吸附性。
  - 碳单质的化学性质：常温稳定；可燃（充分燃烧得 $\ce{CO2}$，不充分得 $\ce{CO}$）；高温下有还原性。
  - 二氧化碳：无色无味气体，密度比空气大，能溶于水；不燃烧也不支持燃烧；能使澄清石灰水变浑浊，能与水反应生成碳酸；固体（干冰）可用于人工降雨。
  - 一氧化碳：无色无味、难溶于水、有毒；可燃（蓝色火焰），有还原性。
- **符号含义**：二氧化碳无毒，但不能供给呼吸；一氧化碳有毒，是因为它与血红蛋白结合，使人缺氧。
- **适用条件**：二氧化碳与一氧化碳的分子构成不同（一个分子多一个氧原子），所以化学性质不同。
- **中考避坑要点**：
  1. 二氧化碳不是空气污染物；引起温室效应加剧是因为含量增加。
  2. 室内放一盆水不能防止煤气中毒，因为一氧化碳难溶于水。

### 17. 燃烧与灭火

- **公式与结论**：燃烧的三个条件缺一不可：可燃物、与氧气（或空气）接触、温度达到着火点。灭火只要破坏其中一个：清除可燃物、隔绝氧气、降温到着火点以下。
- **符号含义**：着火点是物质固有的性质，一般不能改变；降温是降到着火点以下，不是降低着火点。
- **适用条件**：燃料充分燃烧需要足够的氧气和足够大的接触面积。
- **中考避坑要点**：
  1. 灭火说“降低温度到着火点以下”，不能说“降低着火点”。
  2. 可燃性气体与空气混合遇明火可能爆炸，点燃前先验纯；煤气泄漏先关阀门、开窗通风，不要开电器开关。
  3. 酸雨是 $\text{pH} < 5.6$ 的降水，主要由二氧化硫和二氧化氮造成。

## 七、 易错与避坑

综合各单元高频失分点。

### 18. 概念辨析清单

- **公式与结论**：
  - 纯净物只含一种物质；混合物含多种物质（空气、河水、矿泉水、汽水是混合物）。
  - 单质：同种元素组成的纯净物；化合物：不同种元素组成的纯净物；氧化物：由两种元素组成、其中一种是氧元素的化合物。
  - 物理变化无新物质生成；化学变化有新物质生成（常伴随发光、放热、变色、放出气体、生成沉淀）。
  - 催化剂：改变反应速率，本身的质量和化学性质在反应前后不变；不改变生成物的质量。
- **符号含义**：“只由一种元素组成的物质”不一定是单质（可能是混合物，如氧气和臭氧）。
- **适用条件**：分类题和判断题。
- **中考避坑要点**：
  1. 含氧的化合物不一定是氧化物（如 $\ce{KMnO4}$ 含三种元素）。
  2. 催化剂不是只能“加快”，也能“减慢”；催化剂不增加生成物的质量。
  3. 水的净化：沉降、过滤、吸附、消毒、蒸馏中，只有蒸馏能得到纯水；过滤只能除去不溶性杂质；煮沸和蒸馏都能使硬水软化。
  4. 电解水：正极产生氧气，负极产生氢气，体积比约 $1 : 2$（正氧负氢，氢二氧一），说明水由氢元素和氧元素组成。
