# 初中数学公式与结论速查

整理中考常用公式、定理与性质，做题时随手查。

---

## 一、 数与式

数式是代数运算的基石，重点考查符号法则、非负性、运算顺序与因式分解转化。

### 01. 有理数的绝对值与相反数

- **公式与结论**：
  $$|a| = \begin{cases} a & (a > 0) \\ 0 & (a = 0) \\ -a & (a < 0) \end{cases}$$
  相反数性质：$a + (-a) = 0$；若 $a, b$ 互为相反数，则 $a + b = 0$；若 $a, b$ 互为倒数，则 $ab = 1$。
  绝对值非负性：$|a| \ge 0$。
- **符号含义**：$a$ 为任意有理数（实数）；$|a|$ 为 $a$ 的绝对值，几何意义为数轴上表示数 $a$ 的点与原点的距离；$-a$ 为 $a$ 的相反数。
- **适用条件**：全体实数。
- **中考避坑要点**：
  1. 字母 $a$ 本身可正可负，$-a$ 不一定是负数；当 $a < 0$ 时，$-a > 0$。
  2. 化简代数式中的绝对值 $|x - y|$ 时，必须先判定 $x - y$ 的正负性，不可盲目去掉绝对值符号。

---

### 02. 有理数运算法则与混合运算顺序

- **公式与结论**：
  减法转加法：$a - b = a + (-b)$；除法转乘法：$a \div b = a \cdot \frac{1}{b}\ (b \ne 0)$。
  乘法分配律：$a(b + c) = ab + ac$。
  乘方符号法则：正数的任何正整数次幂是正数；负数的奇数次幂是负数，负数的偶数次幂是正数：
  $$(-a)^{2n} = a^{2n}, \quad (-a)^{2n-1} = -a^{2n-1} \quad (n \in \mathbb{N}^+)$$
  混合运算顺序：先乘方，再乘除，最后加减；有括号的先算括号里面的。
- **符号含义**：$a, b, c$ 为有理数；$n$ 为正整数。
- **适用条件**：有理数四则与乘方运算；除数不能为 $0$。
- **中考避坑要点**：
  1. 严格辨析 $(-a)^n$ 与 $-a^n$：底数不同，$(-2)^4 = 16$，而 $-2^4 = -16$。
  2. 除法没有分配律：$a \div (b + c) \ne a \div b + a \div c$；多个连续乘除运算应按从左到右顺序进行。

---

### 03. 科学记数法与近似数

- **公式与结论**：
  绝对值较大的数：$N = a \times 10^n$（其中 $1 \le |a| < 10$，$n$ 为正整数，等于原数整数位数减 $1$）。
  绝对值较小的小数（绝对值小于 $1$ 的非零数）：$N = a \times 10^{-n}$（其中 $1 \le |a| < 10$，$n$ 为正整数，等于原数左边第一个非零数字前所有零的个数，含小数点前的零）。
- **符号含义**：$N$ 为待表示的原数；$a$ 为尾数；$n$ 为 $10$ 的整数指数。
- **适用条件**：大数与微小数的规范记数表示；要求 $1 \le |a| < 10$。
- **中考避坑要点**：
  1. 尾数 $a$ 的取值区间必须满足 $1 \le |a| < 10$；如写成 $25 \times 10^4$ 或 $0.8 \times 10^{-3}$ 均属不规范扣分。
  2. 近似数末尾的“$0$”代表测量精确度，不可随意删去（例如 $3.50$ 精确到百分位，不能简写为 $3.5$）。

---

### 04. 平方根、算术平方根与立方根

- **公式与结论**：
  平方根：若 $x^2 = a\ (a \ge 0)$，则 $x = \pm\sqrt{a}$；其中正的平方根 $\sqrt{a}$ 叫作 $a$ 的算术平方根。
  双重非负性：对于 $\sqrt{a}$，必须 $a \ge 0$ 且 $\sqrt{a} \ge 0$。
  化简基本公式：$(\sqrt{a})^2 = a\ (a \ge 0)$；$\sqrt{a^2} = |a| = \begin{cases} a & (a \ge 0) \\ -a & (a < 0) \end{cases}$。
  立方根：若 $x^3 = a$，则 $x = \sqrt[3]{a}$；$\sqrt[3]{-a} = -\sqrt[3]{a}$。
- **符号含义**：$a$ 为被开方数；$\pm\sqrt{a}$ 为平方根；$\sqrt{a}$ 为算术平方根；$\sqrt[3]{a}$ 为立方根。
- **适用条件**：平方根要求 $a \ge 0$；立方根中 $a$ 可取任意实数。
- **中考避坑要点**：
  1. 审题分清文字与符号：“$9$ 的平方根是 $\pm 3$”，而符号“$\sqrt{9} = 3$”，切勿将 $\sqrt{9}$ 错答为 $\pm 3$。
  2. 化简 $\sqrt{a^2}$ 时绝不可直接写成 $a$，必须先写 $|a|$，再根据 $a$ 的正负判定去绝对值符号。

---

### 05. 幂的运算法则与整数指数幂

- **公式与结论**：
  同底数幂乘法：$a^m \cdot a^n = a^{m+n}$。
  幂的乘方：$(a^m)^n = a^{mn}$。
  积的乘方：$(ab)^n = a^n b^n$。
  同底数幂除法：$a^m \div a^n = a^{m-n}\ (a \ne 0)$。
  零指数幂：$a^0 = 1\ (a \ne 0)$。
  负整数指数幂：$a^{-p} = \frac{1}{a^p}\ (a \ne 0, p \in \mathbb{N}^+)$。
- **符号含义**：$a, b$ 为底数；$m, n$ 为整数；$p$ 为正整数。
- **适用条件**：除法、零指数幂及负整数指数幂要求底数 $a \ne 0$。
- **中考避坑要点**：
  1. 区分同底数幂乘法与幂的乘方：$a^2 \cdot a^3 = a^5$，而 $(a^2)^3 = a^6$，运算性质不可混淆。
  2. 零指数幂与负整数指数幂的前提是底数非零：$0^0$ 与 $0^{-2}$ 均无意义。

---

### 06. 整式乘法与乘法公式

- **公式与结论**：
  单项式乘多项式：$m(a + b + c) = ma + mb + mc$。
  多项式乘多项式：$(a + b)(p + q) = ap + aq + bp + bq$。
  平方差公式：$(a + b)(a - b) = a^2 - b^2$。
  完全平方公式：$(a \pm b)^2 = a^2 \pm 2ab + b^2$。
  高频变形：
  $$a^2 + b^2 = (a + b)^2 - 2ab = (a - b)^2 + 2ab$$
  $$(a + b)^2 - (a - b)^2 = 4ab$$
- **符号含义**：$a, b, m, p, q$ 可表示任意数、单项式或多项式。
- **适用条件**：整式乘法运算与代数式变形。
- **中考避坑要点**：
  1. 完全平方公式展开极易漏掉中间的二倍项：$(a \pm b)^2 \ne a^2 \pm b^2$。
  2. 负号提防：$(-a - b)^2 = (a + b)^2$；$(-a + b)^2 = (a - b)^2$。

---

### 07. 因式分解基本方法

- **公式与结论**：
  提公因式法：$ma + mb + mc = m(a + b + c)$。
  公式法：
  $$a^2 - b^2 = (a + b)(a - b)$$
  $$a^2 \pm 2ab + b^2 = (a \pm b)^2$$
  十字相乘法（补充，做题常用）：$x^2 + (p + q)x + pq = (x + p)(x + q)$。
- **符号含义**：$m$ 为各项公因式；$a, b, x, p, q$ 为单项式或数。
- **适用条件**：多项式化为几个整式的积的形式。
- **中考避坑要点**：
  1. 提公因式漏项：若某项与公因式完全相同，提取公因式后该项留下“$1$”，不可漏掉。
  2. 因式分解必须彻底：分解后每个因式都不能再分解（如 $x^4 - 1 = (x^2 + 1)(x + 1)(x - 1)$）。

---

### 08. 分式的基本性质与四则运算

- **公式与结论**：
  基本性质：$\frac{A}{B} = \frac{A \cdot C}{B \cdot C}, \quad \frac{A}{B} = \frac{A \div C}{B \div C} \quad (B \ne 0, C \ne 0)$。
  乘除法：$\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$；$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c} = \frac{ad}{bc}\ (b \ne 0, c \ne 0, d \ne 0)$。
  加减法：$\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c}$；$\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}\ (b \ne 0, d \ne 0)$。
- **符号含义**：$A, B, C, a, b, c, d$ 为整式；$B$ 中含有字母且 $B \ne 0$。
- **适用条件**：分式有意义的充要条件是分母不等于 $0$；分式值为 $0$ 的条件是分子为 $0$ 且分母不为 $0$。
- **中考避坑要点**：
  1. 分式化简求值中，若自变量取值由考生自行选取，所选值绝不能使原式中任何分式的分母或除式的分子为零。
  2. 分式加减运算在通分时，不能擅自抹去分母（只有解方程时才能去分母）。

---

### 09. 二次根式的性质与运算

- **公式与结论**：
  双重非负性：$\sqrt{a} \ge 0\ (a \ge 0)$。
  乘除法则：$\sqrt{ab} = \sqrt{a}\sqrt{b}\ (a \ge 0, b \ge 0)$；$\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}\ (a \ge 0, b > 0)$。
  加减法则：先化简为最简二次根式，再合并同类二次根式：$m\sqrt{a} + n\sqrt{a} = (m + n)\sqrt{a}$。
  分母有理化：$\frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}\ (a > 0)$；$\frac{1}{\sqrt{a} \pm \sqrt{b}} = \frac{\sqrt{a} \mp \sqrt{b}}{a - b}\ (a \ge 0, b \ge 0, a \ne b)$。
- **符号含义**：$a, b$ 为被开方数；$m, n$ 为根号外系数。
- **适用条件**：被开方数非负；分母不为零。
- **中考避坑要点**：
  1. 最简二次根式两要求：被开方数不含分母；被开方数中不含能开得尽方的因数或因式。
  2. 非同类二次根式不能合并：$\sqrt{2} + \sqrt{3} \ne \sqrt{5}$。

---

## 二、 方程与不等式

方程与不等式是模型思想的核心，重点考查消元降次、根的判别与检验、不等号方向。

### 10. 一元一次方程及其解法

- **公式与结论**：
  标准形式：$ax = b\ (a \ne 0)$，其唯一解为 $x = \frac{b}{a}$。
  等式性质：
  性质 1：若 $a = b$，则 $a \pm c = b \pm c$；
  性质 2：若 $a = b$，则 $ac = bc$；若 $c \ne 0$，则 $\frac{a}{c} = \frac{b}{c}$。
  解方程通用五步法：去分母 $\to$ 去括号 $\to$ 移项 $\to$ 合并同类项 $\to$ 系数化为 $1$。
- **符号含义**：$x$ 为未知数；$a$ 为一次项系数；$b$ 为常数项。
- **适用条件**：只含一个未知数且未知数次数为 $1$ 的整式方程。
- **中考避坑要点**：
  1. 去分母时，不含分母的独立常数项最易漏乘公分母。
  2. 移项必须改变符号；去括号时若括号前为负号，括号内各项必须全部变号。

---

### 11. 二元一次方程组的解法

- **公式与结论**：
  标准形式：$\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$。
  消元策略：
  代入消元法：选系数为 $\pm 1$ 的未知数变形，代入另一个方程；
  加减消元法：使同一个未知数的系数相等（同号相减）或互为相反数（异号相加）。
- **符号含义**：$x, y$ 为两个未知数；$a_i, b_i$ 为系数；$c_i$ 为常数项。
- **适用条件**：含两个未知数的一次方程组。
- **中考避坑要点**：
  1. 加减消元用减法时，若被减项带负号，注意负负得正，防止符号错误。
  2. 代入消元时，求出的表达式必须代入未变形的“另一个”方程，不可代回原方程。

---

### 12. 一元二次方程的四种解法

- **公式与结论**：
  一般形式：$ax^2 + bx + c = 0\ (a \ne 0)$。
  直接开平方法：适用于 $(x + m)^2 = n\ (n \ge 0) \implies x + m = \pm\sqrt{n}$。
  配方法：将二次项系数化为 $1$ 后，两边加上一次项系数一半的平方：
  $$x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = -\frac{c}{a} + \left(\frac{b}{2a}\right)^2 \implies \left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$$
  公式法：当 $b^2 - 4ac \ge 0$ 时，
  $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
  因式分解法：使方程一边为 $0$，另一边分解为两个一次因式的积：$(x - x_1)(x - x_2) = 0 \implies x = x_1\text{ 或 }x = x_2$。
- **符号含义**：$a$ 为二次项系数（$a \ne 0$）；$b$ 为一次项系数；$c$ 为常数项。
- **适用条件**：一元二次方程求解。
- **中考避坑要点**：
  1. 配方法二次项系数不为 $1$ 时，必须先各项同除以二次项系数 $a$，再加一次项系数一半的平方。
  2. 使用因式分解法降次，等号右边必须先整理为 $0$；绝不可在右边非零时直接拆开令因式等于非零常数。

---

### 13. 一元二次方程根的判别式

- **公式与结论**：
  根的判别式：$\Delta = b^2 - 4ac$。
  判别结论：
  当 $\Delta > 0$ 时，方程有两个不相等的实数根；
  当 $\Delta = 0$ 时，方程有两个相等的实数根；
  当 $\Delta < 0$ 时，方程没有实数根；
  当 $\Delta \ge 0$ 时，方程有实数根。
- **符号含义**：$\Delta$ 为判别式；$a, b, c$ 为一般式各项系数。
- **适用条件**：一元二次方程根的个数与存在性判定；必须 $a \ne 0$。
- **中考避坑要点**：
  1. 若方程二次项系数含字母（如 $kx^2 + 2x + 1 = 0$），且题设为“一元二次方程”，则除 $\Delta \ge 0$ 外，必须附加 $k \ne 0$。
  2. 审清“有两个实数根”（$\Delta \ge 0$）与“有两个不相等的实数根”（$\Delta > 0$）的区别。

---

### 14. 一元二次方程根与系数的关系（韦达定理）

- **公式与结论**：
  若方程 $ax^2 + bx + c = 0\ (a \ne 0)$ 的两个实数根为 $x_1, x_2$，则：
  $$x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}$$
  高频对称式变形式：
  $$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2$$
  $$(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2$$
  $$\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1 x_2} \quad (x_1 x_2 \ne 0)$$
- **符号含义**：$x_1, x_2$ 为方程两实根；$a, b, c$ 为各项系数。
- **适用条件**：必须同时满足 $a \ne 0$ 且 $\Delta = b^2 - 4ac \ge 0$。
- **中考避坑要点**：
  1. 逆向求参数时，必须代回判别式检验 $\Delta \ge 0$；若求出的参数使 $\Delta < 0$，该解必须舍去。
  2. 两根之和为 $-\frac{b}{a}$，注意公式自带负号；两根之积为 $\frac{c}{a}$，不带负号。

---

### 15. 分式方程及其解法与增根检验

- **公式与结论**：
  基本解法：方程两边同乘以最简公分母，化为整式方程后求解。
  增根定义：在去分母变形中产生、使分式方程的最简公分母等于 $0$ 的根。
  检验方法：将整式方程求得的解代入最简公分母：若最简公分母不为 $0$，则是原方程的解；若最简公分母为 $0$，则是增根，必须舍去。
- **符号含义**：最简公分母为各分母所有因式的最高次幂的积。
- **适用条件**：解分式方程。
- **中考避坑要点**：
  1. 解分式方程最后一步必须写“检验”步骤，若未写检验文字直接扣分。
  2. “分式方程无解”包含两种可能：化成的整式方程本身无解，或者整式方程解出的根全是增根。

---

### 16. 不等式的基本性质

- **公式与结论**：
  性质 1：若 $a > b$，则 $a \pm c > b \pm c$。
  性质 2：若 $a > b$ 且 $c > 0$，则 $ac > bc, \quad \frac{a}{c} > \frac{b}{c}$。
  性质 3：若 $a > b$ 且 $c < 0$，则 $ac < bc, \quad \frac{a}{c} < \frac{b}{c}$（不等号方向改变）。
- **符号含义**：$a, b$ 为实数；$c$ 为同乘或同除的实数。
- **适用条件**：不等式恒等变形。
- **中考避坑要点**：
  1. 性质 3 是最易扣分点：两边同乘以（或除以）负数时，不等号方向必须立即改变。
  2. 若两边同乘或同除含未知数的代数式，必须先判断该代数式的符号，不可默认其为正。

---

### 17. 一元一次不等式（组）与解集表示

- **公式与结论**：
  不等式组解集口诀（设 $a < b$）：
  $\begin{cases} x > a \\ x > b \end{cases} \implies x > b$（同大取大）；
  $\begin{cases} x < a \\ x < b \end{cases} \implies x < a$（同小取小）；
  $\begin{cases} x > a \\ x < b \end{cases} \implies a < x < b$（大小小大中间找）；
  $\begin{cases} x < a \\ x > b \end{cases} \implies$ 无解（大大小小无处找）。
  数轴表示规则：含等号（$\ge, \le$）用实心点；不含等号（$>, <$）用空心圈；大于向右画，小于向左画。
- **符号含义**：$a, b$ 为不等式边界数值。
- **适用条件**：一元一次不等式及不等式组求解。
- **中考避坑要点**：
  1. 依据不等式组解集或整数解个数反求参数范围时，边界点（能否取等号）必须单独代入原题严格检验。
  2. 在数轴上画解集时，切勿混淆实心圆点与空心圆圈。

---

## 三、 函数

函数是初中代数的综合枢纽，重点考查数形结合、解析式待定系数法、图象变换与最值。

### 18. 平面直角坐标系中的点与几何特征

- **公式与结论**：
  象限符号：第一象限 $(+, +)$；第二象限 $(-, +)$；第三象限 $(-, -)$；第四象限 $(+, -)$。
  坐标轴上的点：$x$ 轴上点纵坐标为 $0$ 即 $(x, 0)$；$y$ 轴上点横坐标为 $0$ 即 $(0, y)$。
  点到坐标轴距离：点 $P(x, y)$ 到 $x$ 轴的距离为 $|y|$；到 $y$ 轴的距离为 $|x|$。
  对称点规律：
  关于 $x$ 轴对称：$(x, y) \to (x, -y)$（横不变，纵相反）；
  关于 $y$ 轴对称：$(x, y) \to (-x, y)$（纵不变，横相反）；
  关于原点对称：$(x, y) \to (-x, -y)$（横纵皆相反）。
  两点距离与中点：
  水平线段：$AB = |x_1 - x_2|$；竖直线段：$CD = |y_1 - y_2|$；
  中点坐标：$M\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$。
- **符号含义**：$(x, y)$ 为平面内点的坐标。
- **适用条件**：平面直角坐标系中点的位置与几何计算。
- **中考避坑要点**：
  1. 点到坐标轴的距离是绝对值，线段长度恒非负，绝不可写成负数。
  2. 平行于坐标轴的线段长计算，必须用大坐标减去小坐标或加绝对值。

---

### 19. 一次函数与正比例函数的图象与性质

- **公式与结论**：
  解析式：$y = kx + b\ (k \ne 0)$；当 $b = 0$ 时为正比例函数 $y = kx$。
  $k, b$ 与图象所在象限：
  $k > 0, b > 0 \implies$ 经过第一、二、三象限；
  $k > 0, b < 0 \implies$ 经过第一、三、四象限；
  $k < 0, b > 0 \implies$ 经过第一、二、四象限；
  $k < 0, b < 0 \implies$ 经过第二、三、四象限。
  增减性：$k > 0$ 时，$y$ 随 $x$ 的增大而增大；$k < 0$ 时，$y$ 随 $x$ 的增大而减小。
  坐标轴交点：与 $y$ 轴交于 $(0, b)$，与 $x$ 轴交于 $\left(-\frac{b}{k}, 0\right)$。
  直线平移：直线 $y = kx + b$ 向上/下平移 $m$ 个单位得 $y = kx + b \pm m$。
- **符号含义**：$k$ 为斜率（比例系数，$k \ne 0$）；$b$ 为直线在 $y$ 轴上的截距。
- **适用条件**：一次函数与正比例函数模型。
- **中考避坑要点**：
  1. 待定系数法设一次函数解析式时，切勿漏写条件 $k \ne 0$。
  2. “截距 $b$”是一个数值（纵坐标），不是坐标 $(0, b)$。

---

### 20. 一次函数与方程、不等式的内在联系

- **公式与结论**：
  与一元一次方程：方程 $kx + b = 0$ 的解 $\Longleftrightarrow$ 直线 $y = kx + b$ 与 $x$ 轴交点的横坐标。
  与一元一次不等式：
  $kx + b > 0$ 的解集 $\Longleftrightarrow$ 直线 $y = kx + b$ 落在 $x$ 轴上方部分对应的自变量 $x$ 的取值范围；
  $kx + b < 0$ 的解集 $\Longleftrightarrow$ 直线落在 $x$ 轴下方部分对应的 $x$ 取值范围。
  与二元一次方程组：方程组 $\begin{cases} y = k_1x + b_1 \\ y = k_2x + b_2 \end{cases}$ 的解 $\Longleftrightarrow$ 对应两条直线的交点坐标 $(x_0, y_0)$。
- **符号含义**：$x_0, y_0$ 为两函数图象交点坐标。
- **适用条件**：数形结合解决一次方程、不等式及方程组。
- **中考避坑要点**：
  1. 由函数图象读不等式 $k_1x + b_1 > k_2x + b_2$ 的解集时，应观察图象位于上方的那条直线，读交点对应的横坐标范围。
  2. 读不等式解集必须写未知数 $x$ 的取值范围，不可错写为坐标或点。

---

### 21. 反比例函数的图象与性质

- **公式与结论**：
  标准解析式：$y = \frac{k}{x}\ (k \ne 0)$，等价于 $xy = k$ 或 $y = kx^{-1}$。
  图象特征：双曲线，关于原点中心对称，两支无限趋近坐标轴但永不相交。
  象限与增减性：
  $k > 0 \implies$ 图象位于第一、三象限；在每个象限内，$y$ 随 $x$ 的增大而减小；
  $k < 0 \implies$ 图象位于第二、四象限；在每个象限内，$y$ 随 $x$ 的增大而增大。
- **符号含义**：$k$ 为反比例系数（$k \ne 0$）；自变量 $x \ne 0$，函数值 $y \ne 0$。
- **适用条件**：反比例函数模型。
- **中考避坑要点**：
  1. 叙述增减性必须带前提“在每个象限内”或“在每一支上”！切不可说“在全体定义域内随 $x$ 增大而减小”，跨象限时增减性不成立。
  2. 反比例函数图象永不经过坐标轴，$x = 0$ 与 $y = 0$ 无图象。

---

### 22. 反比例函数中 $k$ 的几何意义

- **公式与结论**：
  矩形面积模型：过双曲线上任意一点 $P(x, y)$ 向两坐标轴分别作垂线，与坐标轴围成的矩形面积为：
  $$S_{\text{矩形}} = |x| \cdot |y| = |xy| = |k|$$
  直角三角形面积模型：过双曲线上任意一点 $P(x, y)$ 向任意一个坐标轴作垂线，与坐标原点连线围成的直角三角形面积为：
  $$S_{\triangle} = \frac{1}{2}|xy| = \frac{1}{2}|k|$$
- **符号含义**：$P(x, y)$ 为双曲线上任意一点；$k$ 为反比例系数。
- **适用条件**：反比例函数与几何图形面积综合题。
- **中考避坑要点**：
  1. 面积公式中必带绝对值 $|k|$；由面积反求反比例函数解析式时，必须根据双曲线所在象限确定 $k$ 的符号（第二、四象限时 $k < 0$）。
  2. 双曲线上两点构成的平行四边形或梯形面积，优先转化为坐标乘积差计算。

---

### 23. 二次函数的三种解析式及选取策略

- **公式与结论**：
  一般式：$y = ax^2 + bx + c\ (a \ne 0)$（已知任意三点坐标时选取）。
  顶点式：$y = a(x - h)^2 + k\ (a \ne 0)$（已知顶点坐标 $(h, k)$、对称轴 $x = h$ 或最值时选取）。
  交点式（两根式）：$y = a(x - x_1)(x - x_2)\ (a \ne 0)$（已知抛物线与 $x$ 轴的两交点坐标 $(x_1, 0), (x_2, 0)$ 时选取）。
- **符号含义**：$a$ 为二次项系数；$(h, k)$ 为顶点坐标；$x_1, x_2$ 为与 $x$ 轴交点的横坐标。
- **适用条件**：二次函数解析式求解（待定系数法）。
- **中考避坑要点**：
  1. 顶点式中的负号陷阱：若顶点为 $(-1, 2)$，设式应为 $y = a(x + 1)^2 + 2$，不可写成 $y = a(x - 1)^2 + 2$。
  2. 交点式中的 $x_1, x_2$ 必须是抛物线与 $x$ 轴的交点横坐标，不能代入与 $y$ 轴的交点。

---

### 24. 二次函数的图象与核心性质

- **公式与结论**：
  配方形式：
  $$y = ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a}$$
  开口方向：$a > 0$ 开口向上；$a < 0$ 开口向下。
  对称轴：直线 $x = -\frac{b}{2a}$。
  顶点坐标：$\left(-\frac{b}{2a}, \frac{4ac - b^2}{4a}\right)$。
  增减性：
  $a > 0$ 时，在对称轴左侧（$x \le -\frac{b}{2a}$），$y$ 随 $x$ 增大而减小；在对称轴右侧（$x \ge -\frac{b}{2a}$），$y$ 随 $x$ 增大而增大；
  $a < 0$ 时，在对称轴左侧（$x \le -\frac{b}{2a}$），$y$ 随 $x$ 增大而增大；在对称轴右侧（$x \ge -\frac{b}{2a}$），$y$ 随 $x$ 增大而减小。
  最值：当 $x = -\frac{b}{2a}$ 时，函数取得最值，最值为 $\frac{4ac - b^2}{4a}$（$a > 0$ 时为最小值；$a < 0$ 时为最大值）。
- **符号含义**：$a, b, c$ 为一般式各项系数。
- **适用条件**：全体实数范围内二次函数图象与性质分析。
- **中考避坑要点**：
  1. “函数的最大值或最小值”指纵坐标 $y$ 的值，不能把横坐标 $x = -\frac{b}{2a}$ 错答为最值。
  2. 若自变量 $x$ 限制在闭区间 $m \le x \le n$ 内，求最值必须先判断对称轴是否在区间内，不能直接套用顶点纵坐标。

---

### 25. 二次函数的平移规律与图象综合判定

- **公式与结论**：
  平移法则：“左加右减，上加下减”（自变量 $x$ 变化控制左右，常数项变化控制上下）：
  抛物线 $y = ax^2$ 向右平移 $h$ 个单位、向上平移 $k$ 个单位 $\implies y = a(x - h)^2 + k$。
  系数符号综合口诀：
  $a$ 看开口：开口向上 $a > 0$，开口向下 $a < 0$；
  $b$ 看对称轴：“左同右异”（对称轴在 $y$ 轴左侧 $\implies ab > 0$；对称轴在 $y$ 轴右侧 $\implies ab < 0$；对称轴为 $y$ 轴 $\implies b = 0$）；
  $c$ 看与 $y$ 轴交点：交于正半轴 $c > 0$，交于负半轴 $c < 0$，过原点 $c = 0$；
  $\Delta$ 看与 $x$ 轴交点：$2$ 个交点 $\Delta > 0$；$1$ 个交点（切点）$\Delta = 0$；$0$ 个交点 $\Delta < 0$。
- **符号含义**：$h, k$ 为平移距离；$a, b, c$ 决定抛物线形状与位置。
- **适用条件**：抛物线平移与图象识别。
- **中考避坑要点**：
  1. 左右平移只对“自变量 $x$ 本身”进行加减，如 $y = a(2x - 1)^2$ 向左平移 $1$ 个单位，是将 $x$ 变为 $x + 1$。
  2. 平移只改变顶点位置，不改变抛物线开口大小和方向，即二次项系数 $a$ 恒定不变。

---

## 四、 图形的性质

几何性质注重逻辑推理与公理体系，重点考查全等三角形判定、特殊四边形、圆的定理与分类讨论。

### 26. 线段、射线与角的基本性质

- **公式与结论**：
  基本事实：两点确定一条直线；两点之间，线段最短。
  线段中点：若 $M$ 是线段 $AB$ 的中点，则 $AM = MB = \frac{1}{2}AB$。
  角的性质：
  对顶角相等；
  余角性质：同角（或等角）的余角相等（若 $\angle 1 + \angle 2 = 90^\circ, \angle 1 + \angle 3 = 90^\circ \implies \angle 2 = \angle 3$）；
  补角性质：同角（或等角）的补角相等（若 $\angle 1 + \angle 2 = 180^\circ, \angle 1 + \angle 3 = 180^\circ \implies \angle 2 = \angle 3$）。
  垂线性质：连接直线外一点与直线上各点的所有线段中，垂线段最短。
- **符号含义**：$A, B$ 为端点；$M$ 为中点；$\angle$ 为角。
- **适用条件**：平面几何基础概念与度量。
- **中考避坑要点**：
  1. 严格辨析“两点之间线段最短”（点到点）与“垂线段最短”（点到直线）。
  2. 角的度、分、秒换算是 $60$ 进制（$1^\circ = 60', 1' = 60''$），不可按十进制计算。

---

### 27. 平行线的性质与判定

- **公式与结论**：
  平行公理：经过直线外一点，有且只有一条直线与这条直线平行；若 $a \parallel b$ 且 $b \parallel c$，则 $a \parallel c$。
  判定定理（由角推线）：
  同位角相等 $\implies$ 两直线平行；
  内错角相等 $\implies$ 两直线平行；
  同旁内角互补 $\implies$ 两直线平行。
  性质定理（由线推角）：
  两直线平行 $\implies$ 同位角相等；
  两直线平行 $\implies$ 内错角相等；
  两直线平行 $\implies$ 同旁内角互补。
- **符号含义**：$\parallel$ 表示平行。
- **适用条件**：同一平面内直线的位置关系。
- **中考避坑要点**：
  1. 因果颠倒失分：证明平行线必须用判定定理；利用平行求角度必须用性质定理，几何书写不可颠倒依据。
  2. 同旁内角是“互补”（相加等于 $180^\circ$），不是相等。

---

### 28. 三角形的三边关系与内角外角性质

- **公式与结论**：
  三边关系：三角形任意两边之和大于第三边，任意两边之差小于第三边（第三边范围：$|a - b| < c < a + b$）。
  内角和定理：三角形三个内角和等于 $180^\circ$。
  外角性质：
  三角形的一个外角等于与它不相邻的两个内角的和（$\angle ACD = \angle A + \angle B$）；
  三角形的一个外角大于与它不相邻的任何一个内角。
  多边形角度：$n$ 边形内角和为 $(n - 2) \times 180^\circ$；任意凸多边形外角和恒为 $360^\circ$。
- **符号含义**：$a, b, c$ 为三角形三边长；$n$ 为多边形边数（$n \ge 3$）。
- **适用条件**：任意三角形与多边形。
- **中考避坑要点**：
  1. 检验三条线段能否组成三角形，只需验证“较短两边之和大于最长边”即可。
  2. 任意多边形的外角和恒为 $360^\circ$，与边数 $n$ 完全无关。

---

### 29. 全等三角形的性质与判定

- **公式与结论**：
  全等性质：全等三角形对应边相等，对应角相等；对应高、中线、角平分线相等，面积与周长相等。
  一般三角形判定方法：
  $\text{SSS}$（边边边）；$\text{SAS}$（边角边，角必须是两边的夹角）；
  $\text{ASA}$（角边角）；$\text{AAS}$（角角边）。
  直角三角形专用判定：$\text{HL}$（斜边、直角边）。
  角平分线性质与判定：
  性质：角的平分线上的点到角的两边的距离相等；
  判定：角的内部到角的两边距离相等的点在角的平分线上。
- **符号含义**：$\cong$ 为全等；$\text{S}$ 表示边，$\text{A}$ 表示角，$\text{H}$ 表示斜边，$\text{L}$ 表示直角边。
- **适用条件**：三角形全等证明。
- **中考避坑要点**：
  1. 严禁使用 $\text{SSA}$（边边角）和 $\text{AAA}$（角角角）证明全等，这两个不是判定定理。
  2. $\text{SAS}$ 中的角必须是两边的“夹角”，若是其他对角则不成立。

---

### 30. 等腰三角形与等边三角形的性质与判定

- **公式与结论**：
  等腰三角形：
  性质：等边对等角（$\angle B = \angle C$）；“三线合一”（底边上的高、底边上的中线、顶角的平分线互相重合）。
  判定：等角对等边。
  等边三角形：三边相等，三个内角都等于 $60^\circ$；判定：三边相等，或有一个内角是 $60^\circ$ 的等腰三角形。
  含 $30^\circ$ 角的直角三角形：在直角三角形中，如果有一个锐角等于 $30^\circ$，那么它所对的直角边等于斜边的一半（$a = \frac{1}{2}c$）。
  直角三角形斜边中线定理：直角三角形斜边上的中线等于斜边的一半（$CD = \frac{1}{2}AB$）。
- **符号含义**：腰长、底边、顶角、底角。
- **适用条件**：等腰三角形、等边三角形及直角三角形。
- **中考避坑要点**：
  1. 等腰三角形高频分类讨论：已知两边长为 $4$ 和 $9$，腰只能是 $9$（$4, 4, 9$ 不能成三角形）；已知等腰三角形一内角为 $70^\circ$，该角可能是顶角或底角，需分类讨论。
  2. “三线合一”仅对底边和顶角成立，腰上的中线与高不重合。

---

### 31. 勾股定理及其逆定理

- **公式与结论**：
  勾股定理：直角三角形两直角边 $a, b$ 的平方和等于斜边 $c$ 的平方：
  $$a^2 + b^2 = c^2$$
  勾股定理逆定理：如果三角形的三边长 $a, b, c$ 满足 $a^2 + b^2 = c^2$，那么这个三角形是直角三角形（最长边 $c$ 所对的角是直角）。
  常见勾股数（正整数三元组）：
  $(3, 4, 5), \quad (5, 12, 13), \quad (6, 8, 10), \quad (7, 24, 25), \quad (8, 15, 17), \quad (9, 40, 41)$。
- **符号含义**：$a, b$ 为直角边长；$c$ 为斜边长。
- **适用条件**：直角三角形边长计算与直角判定。
- **中考避坑要点**：
  1. 未指明斜边的直角三角形求边长必须分类讨论：已知两边为 $3, 4$，第三边可能是斜边（$5$），也可能是直角边（$\sqrt{4^2-3^2}=\sqrt{7}$）。
  2. 勾股数必须是正整数，含有根号或小数的边长组合不是勾股数。

---

### 32. 平行四边形的性质与判定

- **公式与结论**：
  性质：对边平行且相等；对角相等，邻角互补；对角线互相平分；平行四边形是中心对称图形（对称中心是对角线交点）。
  判定方法（五种）：
  ① 两组对边分别平行的四边形；
  ② 两组对边分别相等的四边形；
  ③ 一组对边平行且相等的四边形；
  ④ 两组对角分别相等的四边形；
  ⑤ 对角线互相平分的四边形。
- **符号含义**：$\square ABCD$ 表示平行四边形。
- **适用条件**：平行四边形性质与判定。
- **中考避坑要点**：
  1. “一组对边平行，另一组对边相等”不能判定平行四边形（可能为等腰梯形）。
  2. 一组对边平行且相等的判定中，“平行”与“相等”必须属于同一组对边。

---

### 33. 矩形、菱形与正方形的性质与判定

- **公式与结论**：
  矩形：
  性质：具有平行四边形所有性质；四个角都是直角；对角线相等且互相平分。
  判定：有一个角是直角的平行四边形；对角线相等的平行四边形；有三个角是直角的四边形。
  菱形：
  性质：具有平行四边形所有性质；四条边都相等；对角线互相垂直平分，且每条对角线平分一组对角。
  面积：$S = \frac{1}{2}d_1 d_2$（对角线乘积的一半）。
  判定：有一组邻边相等的平行四边形；对角线互相垂直的平行四边形；四条边都相等的四边形。
  正方形：
  性质：兼具矩形和菱形的所有性质；四边相等、四角皆直角、对角线垂直平分且相等。
  判定：有一个角是直角的菱形，或有一组邻边相等的矩形。
- **符号含义**：$d_1, d_2$ 为菱形两条对角线长。
- **适用条件**：特殊平行四边形证明与计算。
- **中考避坑要点**：
  1. 证明正方形通常需“两步走”：先证其为矩形（或菱形），再证明其具备菱形（或矩形）的特征，不可一步得出结论。
  2. 对角线互相垂直的四边形面积等于对角线乘积一半，但该四边形不一定是菱形。

---

### 34. 三角形中位线定理与多边形中点图形

- **公式与结论**：
  三角形中位线定义：连接三角形两边中点的线段。
  中位线定理：三角形的中位线平行于第三边，并且等于第三边的一半：
  $$DE \parallel BC, \quad DE = \frac{1}{2}BC$$
  中点四边形规律（补充，做题常用）：顺次连接任意四边形各边中点所得的四边形是平行四边形；
  若原四边形对角线互相垂直，则中点四边形是矩形；
  若原四边形对角线相等，则中点四边形是菱形；
  若原四边形对角线垂直且相等，则中点四边形是正方形。
- **符号含义**：$DE$ 为中位线；$BC$ 为对应底边。
- **适用条件**：几何图形中出现多个边中点时。
- **中考避坑要点**：
  1. 区分中位线与中线：中位线连两边中点；中线连顶点与对边中点。
  2. 几何题中出现中点时，首选构造中位线或直角三角形斜边中线作为辅助线突破口。

---

### 35. 轴对称与旋转图形的性质

- **公式与结论**：
  轴对称性质：对应线段相等，对应角相等；对应点所连线段被对称轴垂直平分。
  线段垂直平分线：线段垂直平分线上的点到线段两端点的距离相等；到线段两端点距离相等的点在线段垂直平分线上。
  旋转性质：对应点到旋转中心的距离相等；对应点与旋转中心连线的夹角等于旋转角；旋转前后的图形全等。
  中心对称性质：中心对称的两个图形全等；对称点连线都经过对称中心且被对称中心平分。
- **符号含义**：对称轴、旋转中心、旋转角 $\alpha$。
- **适用条件**：图形变换与几何全等转化。
- **中考避坑要点**：
  1. 描述旋转变换时，旋转中心、旋转方向（顺时针/逆时针）、旋转角三要素必须完整。
  2. 轴对称折叠本质是全等变换：折痕即为对应点连线的垂直平分线，折叠前后对应边、对应角严格相等。

---

### 36. 垂径定理与圆心角、弧、弦的关系

- **公式与结论**：
  垂径定理：垂直于弦的直径平分弦，并且平分弦所对的两条弧。
  推论：平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧。
  垂径直角三角形计算模型：设圆半径为 $r$，弦长为 $a$，弦心距为 $d$，则：
  $$r^2 = d^2 + \left(\frac{a}{2}\right)^2$$
  圆心角、弧、弦关系定理：在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦相等；如果圆心角、弧、弦中有一组量相等，那么其余各组量也分别相等。
- **符号含义**：$r$ 为圆半径；$d$ 为弦心距；$a$ 为弦长。
- **适用条件**：圆内线段与弦长计算。
- **中考避坑要点**：
  1. 垂径定理推论中必须明确“平分弦（不是直径）”：因为圆的任意两条直径互相平分但不一定垂直。
  2. 圆心角、弧、弦定理必须在“同圆或等圆中”才成立，不同圆中不能简单套用。

---

### 37. 圆周角定理及其推论

- **公式与结论**：
  圆周角定理：在同圆或等圆中，同弧或等弧所对的圆周角相等，都等于这条弧所对的圆心角的一半：
  $$\angle ACB = \frac{1}{2}\angle AOB$$
  直径与直角推论：半圆（或直径）所对的圆周角是直角（$90^\circ$）；$90^\circ$ 的圆周角所对的弦是直径。
  圆内接四边形性质：圆内接四边形的对角互补（$\angle A + \angle C = 180^\circ$），且任何一个外角等于它的内对角。
- **符号含义**：$\angle ACB$ 为圆周角；$\angle AOB$ 为同弧所对圆心角。
- **适用条件**：圆中角度计算与几何证明。
- **中考避坑要点**：
  1. 一条弦所对的圆周角有两种情况：优弧上的角与劣弧上的角互补，未明确图象时必须分类讨论。
  2. 遇直径构造直角（连直径所对的圆周角得 $90^\circ$ 直角三角形）是圆中最核心的辅助线方法。

---

### 38. 直线与圆的位置关系及切线的性质与判定

- **公式与结论**：
  位置关系判断（圆心到直线距离为 $d$，半径为 $r$）：
  $d > r \Longleftrightarrow$ 直线与圆相离（$0$ 个公共点）；
  $d = r \Longleftrightarrow$ 直线与圆相切（$1$ 个公共点）；
  $d < r \Longleftrightarrow$ 直线与圆相交（$2$ 个公共点）。
  切线性质定理：圆的切线垂直于经过切点的半径。
  切线判定定理：经过半径的外端并且垂直于这条半径的直线是圆的切线。
  切线长定理：从圆外一点引圆的两条切线，它们的切线长相等，圆心和这一点的连线平分两条切线的夹角（$PA = PB, \angle APO = \angle BPO$）。
- **符号含义**：$d$ 为圆心到直线距离；$r$ 为半径；$P$ 为切线长交点；$A, B$ 为切点。
- **适用条件**：圆的切线判定与性质应用。
- **中考避坑要点**：
  1. 切线证明辅助线两条铁律：
     ①“直线过圆上已知点” $\implies$ 连半径，证垂直；
     ②“未知直线与圆有无公共点” $\implies$ 作垂直，证 $d = r$。
  2. 题中出现已知切线时，必须第一时间连过切点的半径并标出垂直符号。

---

## 五、 图形的度量

度量计算关注几何量化，重点考查公式对应、扇形与圆锥展开、坐标系割补面积模型。

### 39. 常见平面图形的周长与面积公式

- **公式与结论**：
  三角形：$S = \frac{1}{2}ah$；等边三角形：$S = \frac{\sqrt{3}}{4}a^2$。
  平行四边形：$S = ah$。
  菱形：$S = ah = \frac{1}{2}d_1 d_2$。
  梯形：$S = \frac{1}{2}(a + b)h$。
  圆的周长与面积：$C = 2\pi r = \pi d$；$S = \pi r^2$。
  面积模型：同底等高（或等底等高）的三角形面积相等；高相等时面积比等于底边长之比。
- **符号含义**：$a, b$ 为边长或上底、下底；$h$ 为对应高；$d_1, d_2$ 为菱形对角线长；$r$ 为圆半径。
- **适用条件**：几何图形周长与面积计算。
- **中考避坑要点**：
  1. 三角形底边与高必须严格对应，钝角三角形的高常落在三角形外部。
  2. 区分圆周长 $C = 2\pi r$ 与面积 $S = \pi r^2$，不可把平方与倍数记混。

---

### 40. 弧长与扇形面积公式

- **公式与结论**：
  弧长公式：
  $$l = \frac{n\pi r}{180}$$
  扇形面积公式：
  $$S = \frac{n\pi r^2}{360} = \frac{1}{2}lr$$
- **符号含义**：$n$ 为圆心角的度数值（代入时不带度符号 $^\circ$）；$r$ 为圆的半径；$l$ 为弧长；$S$ 为扇形面积。
- **适用条件**：圆弧长度与扇形面积计算。
- **中考避坑要点**：
  1. 公式中的 $n$ 仅为数值，代入计算时严禁带单位 $^\circ$（例如 $60^\circ$ 的圆心角，代入 $n = 60$ 而非 $60^\circ$）。
  2. 熟记 $S = \frac{1}{2}lr$，在已知弧长和半径时比角度公式更简洁高效。

---

### 41. 圆柱与圆锥的侧面展开及度量

- **公式与结论**：
  圆柱：底面半径为 $r$，高为 $h$。
  底面积 $S_{\text{底}} = \pi r^2$；侧面积 $S_{\text{侧}} = 2\pi rh$；全面积 $S_{\text{全}} = 2\pi r^2 + 2\pi rh$；体积 $V = \pi r^2 h$。
  圆锥：底面半径为 $r$，母线长为 $l$，高为 $h$（满足勾股关系 $r^2 + h^2 = l^2$）。
  侧面展开图为扇形，其半径为母线长 $l$，弧长为底面圆周长 $2\pi r$；
  侧面积：$S_{\text{侧}} = \frac{1}{2} \cdot 2\pi r \cdot l = \pi rl$；
  全面积：$S_{\text{全}} = \pi r^2 + \pi rl$；
  展开图圆心角：$n = \frac{r}{l} \times 360$。
- **符号含义**：$r$ 为底面半径；$l$ 为母线长；$h$ 为圆锥高；$n$ 为侧面展开图扇形圆心角度数。
- **适用条件**：立体图形表面展开与度量计算。
- **中考避坑要点**：
  1. 圆锥侧面展开图扇形的半径是圆锥的母线长 $l$，绝不是圆锥的高 $h$。
  2. 侧面展开图扇形的弧长恰好等于圆锥底面圆的周长 $2\pi r$。

---

### 42. 平面直角坐标系中的多边形面积计算方法

- **公式与结论**：
  水平/铅垂底边法：
  若底边平行于 $x$ 轴（长为 $|x_B - x_C|$），则 $S_{\triangle} = \frac{1}{2}|x_B - x_C| \cdot |y_A - y_B|$；
  若底边平行于 $y$ 轴（长为 $|y_B - y_C|$），则 $S_{\triangle} = \frac{1}{2}|y_B - y_C| \cdot |x_A - x_B|$。
  铅垂高模型（抛物线面积题）：
  $$S_{\triangle} = \frac{1}{2} \cdot h_{\text{铅}} \cdot d_{\text{水}}$$
  （其中 $h_{\text{铅}} = y_{\text{上}} - y_{\text{下}}$ 为铅垂线段长，$d_{\text{水}} = |x_{\text{右}} - x_{\text{左}}|$ 为水平宽）。
  矩形割补法：通过作坐标轴平行线将倾斜多边形补成外接矩形，用矩形面积减去周围直角三角形面积。
- **符号含义**：$h_{\text{铅}}$ 为铅垂高；$d_{\text{水}}$ 为水平宽。
- **适用条件**：函数与平面直角坐标系中的三角形及多边形面积计算。
- **中考避坑要点**：
  1. 铅垂高必须是“上方图象纵坐标减去下方图象纵坐标”，防止符号颠倒导致线段长为负。
  2. 割补法求点坐标差值时，务必注意点所在象限的正负符号。

---

## 六、 统计与概率

统计与概率重点考查平均数、中位数、众数与方差的计算与决策，以及频数频率、统计图表与简单随机事件概率。

### 43. 数据的集中趋势：平均数、中位数与众数

- **公式与结论**：
  算术平均数：$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$。
  加权平均数：$\bar{x} = \frac{x_1 w_1 + x_2 w_2 + \cdots + x_n w_n}{w_1 + w_2 + \cdots + w_n}$（若各权重以百分比给出且和为 $1$，则分母为 $1$）。
  中位数：将一组数据按大小顺序排列：
  若数据个数 $n$ 为奇数，第 $\frac{n+1}{2}$ 个数据为中位数；
  若数据个数 $n$ 为偶数，中间两个数据（第 $\frac{n}{2}$ 个和第 $\frac{n}{2} + 1$ 个）的算术平均数为中位数。
  众数：一组数据中出现次数最多的数据（众数可以有多个，也可以没有）。
- **符号含义**：$\bar{x}$ 为平均数；$w_i$ 为数据的权（权重）；$n$ 为数据总项数。
- **适用条件**：分析一组数据的集中水平与代表值。
- **中考避坑要点**：
  1. 找中位数前必须先将数据“从小到大（或从大到小）排序”，切忌直接取乱序序列中间的数。
  2. 众数是“出现次数最多的数据本身”，而不是该数据出现的频数（次数）。

---

### 44. 数据的离散程度：方差与标准差

- **公式与结论**：
  方差公式：
  $$s^2 = \frac{1}{n}\left[(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2\right]$$
  标准差：$s = \sqrt{s^2}$。
  方差的性质与决策依据：
  方差越大，数据的波动越大；方差越小，数据的波动越小，表现越稳定。
  数据线性变换的方差规律：若每个数据都加上常数 $b$（即 $x_i' = x_i + b$），方差不变；若每个数据都乘常数 $a$（即 $x_i' = ax_i$），新方差变为 $a^2 s^2$。
- **符号含义**：$s^2$ 为方差；$s$ 为标准差；$\bar{x}$ 为样本平均数；$n$ 为样本容量。
- **适用条件**：衡量多组数据波动幅度大小及稳定性高低的比较。
- **中考避坑要点**：
  1. 评判选手或产品质量时，必须遵循“先比平均数（水平高低），平均数相同时再比方差（稳定程度）”。
  2. 算方差前必须准确算出平均数 $\bar{x}$，减法中的负离差平方后必为非负数。

---

### 45. 频数、频率与统计图表综合应用

- **公式与结论**：
  频数与频率公式：
  $$\text{频率} = \frac{\text{频数}}{\text{样本容量（数据总数）}}, \quad \text{频数} = \text{样本容量} \times \text{频率}$$
  各组频率之和等于 $1$；各组频数之和等于样本容量。
  扇形统计图圆心角：
  $$\text{圆心角度数} = 360^\circ \times \text{该部分所占百分比（频率）}$$
  样本估计总体：总体中某类数量估计值 $= \text{总体总数} \times \text{样本中该类比例}$。
- **符号含义**：频数（出现的绝对次数）；频率（占总体的相对比例）。
- **适用条件**：统计图表（条形图、折线图、扇形图、频数分布直方图）信息提取与总体推断。
- **中考避坑要点**：
  1. 扇形统计图计算圆心角必须乘以 $360^\circ$，切勿错乘 $180^\circ$ 或 $100$。
  2. 样本估计总体的结果是估计值，不是确切数值，解释题干实际含义时注意表述严谨。

---

### 46. 简单随机事件的概率与求法

- **公式与结论**：
  概率的范围：对于任意事件 $A$，$0 \le P(A) \le 1$。
  必然事件：$P(A) = 1$；不可能事件：$P(A) = 0$；随机事件：$0 < P(A) < 1$。
  等可能事件概率公式（古典概型）：
  $$P(A) = \frac{m}{n} = \frac{\text{事件 } A \text{ 包含的可能结果数}}{\text{所有可能出现的结果总数}}$$
  几何概型（面积比）：$P(A) = \frac{S_A}{S_{\text{总}}}$。
  两步或多步试验求概率基本方法：列表法（两步试验）、画树状图法（两步及以上试验）。
- **符号含义**：$P(A)$ 为事件 $A$ 发生的概率；$m, n$ 分别为符合条件的结果数与所有等可能结果总数。
- **适用条件**：所有可能结果数有限且每种结果出现可能性均等的随机试验。
- **中考避坑要点**：
  1. 摸球或抽卡试验中，必须审清“放回”还是“不放回”：不放回抽样中，第二次抽取不能取自身，结果总数减少且对角线元素剔除。
  2. 求概率必须先列举出全部等可能结果（列表或画树状图），不能凭空猜测或漏解。

---

## 七、 易错与答题避坑要诀

| 易错类别 / 考查关键词 | 隐含数学条件与考查陷阱 | 答题避坑要诀与规范操作 |
| :--- | :--- | :--- |
| **相反数与绝对值化简** | 字母符号未知，$-a$ 不一定是负数；$|a| \ge 0$ | 化简代数式中的绝对值必须先判定式子整体正负，负项变号时括号整体变号 |
| **非负数之和为零模型** | $|A| + \sqrt{B} + C^2 = 0$ | 几个非负数之和为零，则每个非负数都必须同时等于零（$A=0, B=0, C=0$） |
| **科学记数法 $a$ 与 $n$** | 尾数要求 $1 \le \|a\| < 10$；小数负指数与前置零个数对应 | 检查 $a$ 的范围不能等于或大于 $10$；负指数 $n$ 为首个非零数字前所有零个数 |
| **分式有意义与值为零** | 分式有意义需分母非零；值为零需分子为零且分母非零 | 选值代入分式严禁使原式中任何分母为零；求字母值后必须代入分母检验非零 |
| **分式方程增根与无解** | 去分母转化为整式方程可能产生增根 | 解分式方程最后必须写“检验”步骤；无解包含整式方程无解与所有解均为增根 |
| **二次方程二次项系数非零** | 题目写“关于 $x$ 的一元二次方程”隐含 $a \ne 0$ | 方程二次项系数含参数时，必须附加 $a \ne 0$；若未注明是一元二次方程需分类讨论 |
| **根的判别式与存在性** | “有两个实数根”包含相等实根；“有两个不相等实数根”严格大于 | 有实根列 $\Delta \ge 0$；有不相等实根列 $\Delta > 0$；无实根列 $\Delta < 0$ |
| **韦达定理使用前提** | 使用根与系数关系必须保证两实根真实存在 | 用韦达定理求得参数后，必须代回判别式检验 $\Delta \ge 0$，舍去伪解 |
| **不等式两边同乘除负数** | 不等式同乘除负数不等号必须改变方向 | 涉及字母参数同乘除时，必须先分类讨论该字母的正负性，不可默认正数 |
| **不等式组边界等号判定** | 反求参数范围时边界点能否取等极易出错 | 将边界值直接代入原不等式组检验，核对解集或整数解个数是否完全相符 |
| **反比例函数单调性表述** | 双曲线断开为两支，不可跨象限判断增减 | 叙述性质必须明确写出“在每一个象限内”，严禁写“在全体自变量范围内” |
| **反比例面积与系数正负** | 几何面积 $S = \|k\|$，反求解析式易漏负号 | 图象在第二、四象限时 $k$ 必为负数，由面积求出数值后必须根据象限加上负号 |
| **二次函数区间最值** | 闭区间 $m \le x \le n$ 内的最值不一定是顶点 | 先求对称轴横坐标是否在区间内；若在区间内结合开口算顶点，若在区间外直接比端点 |
| **等腰三角形分类讨论** | 未明确指明腰与底边，或未明确指明顶角与底角 | 已知两边需分哪条为腰并检验三角形三边关系；已知一角需分顶角或底角讨论 |
| **直角三角形勾股分类讨论** | 题干仅给两条边长，未指明哪条边是斜边 | 较大边可能是斜边，也可能是直角边，必须分情况列勾股定理求解 |
| **圆中弦所对的圆周角** | 一条弦所对的圆周角在优弧和劣弧各有一个 | 题干仅提弦未给图时，圆周角有两解且互补（相加等于 $180^\circ$） |
| **切线证明两条辅助线铁律** | 点在圆上与点在圆外辅助线作法不同 | 有交点连半径证垂直（角为 $90^\circ$）；无交点作垂直证半径（距离 $d = r$） |
| **弧长扇形公式度数代入** | 公式 $l = \frac{n\pi r}{180}$ 中 $n$ 为纯数值 | 代入计算时代入数值即可，严禁带度符号 $^\circ$ 代入（如 $60^\circ$ 代入 $60$） |
| **几何推理因果规范** | 判定定理与性质定理混淆，步骤因果颠倒 | 证明平行用判定，求角相等用性质；书写推理必须“由已知推未知”，不可倒果为因 |
| **实际问题验根与单位** | 方程与函数应用题自变量受实际背景制约 | 算出未知数后必须根据实际意义检验（边长大于零、人数为正整数等），并统一单位 |
