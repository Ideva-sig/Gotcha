# 初中物理公式与物理量速查

按章节整理中考常用公式、物理量和单位，做题时随手查。

---

## 一、 力学与运动学

计算量大，重点考查单位统一、模型受力分析及机械效率综合应用。

### 01. 速度与平均速度

- **公式与变形式**：
  $$v = \frac{s}{t} \quad \Longleftrightarrow \quad s = vt, \quad t = \frac{s}{v}$$
  $$v_{\text{平}} = \frac{s_{\text{总}}}{t_{\text{总}}} = \frac{s_1 + s_2 + \dots}{t_1 + t_2 + \dots}$$
- **各物理量含义与法定单位**：
  - $v$：速度（表示物体运动快慢的物理量），单位：米每秒（$\text{m/s}$）或千米每小时（$\text{km/h}$）
  - $s$：路程（物体运动轨迹的长度），单位：米（$\text{m}$）或千米（$\text{km}$）
  - $t$：时间（运动过程经历的时间），单位：秒（$\text{s}$）或小时（$\text{h}$）
  - $v_{\text{平}}$：平均速度（粗略描述变速运动快慢），单位：米每秒（$\text{m/s}$）
- **适用条件**：匀速直线运动（瞬时速度恒定），或变速运动的全程/某路段平均速度。
- **中考避坑要点**：
  1. **单位严格对应**：若速度用 $\text{m/s}$，则路程必须用 $\text{m}$、时间必须用 $\text{s}$；若速度用 $\text{km/h}$，则路程用 $\text{km}$、时间用 $\text{h}$。换算关系：$1\text{ m/s} = 3.6\text{ km/h}$。
  2. **平均速度禁区**：绝不能把平均速度算成速度的算术平均值（即 $v_{\text{平}} \neq \frac{v_1 + v_2}{2}$），必须严格用“总路程除以总时间”（包含中途休息和停留时间）。

### 02. 质量与密度

- **公式与变形式**：
  $$\rho = \frac{m}{V} \quad \Longleftrightarrow \quad m = \rho V, \quad V = \frac{m}{\rho}$$
- **各物理量含义与法定单位**：
  - $\rho$：密度（某种物质单位体积的质量），单位：千克每立方米（$\text{kg/m}^3$）或克每立方厘米（$\text{g/cm}^3$）
  - $m$：质量（物体所含物质的多少），单位：千克（$\text{kg}$）或克（$\text{g}$）
  - $V$：体积（物体所占空间的大小），单位：立方米（$\text{m}^3$）或立方厘米（$\text{cm}^3$）
- **适用条件**：均质物体，或计算混合物的平均密度。
- **中考避坑要点**：
  1. **单位换算**：$1\text{ g/cm}^3 = 1.0 \times 10^3\text{ kg/m}^3$；$1\text{ m}^3 = 10^3\text{ dm}^3(\text{L}) = 10^6\text{ cm}^3(\text{mL})$。
  2. **物质属性本质**：密度是物质本身的特性，与物体的质量大小、体积大小无关。不能根据 $\rho = m/V$ 误判“密度与质量成正比”。但密度与状态和温度有关（如水结冰，质量 $m$ 不变，体积 $V$ 变大，密度变小：$\rho_{\text{冰}} = 0.9 \times 10^3\text{ kg/m}^3$）。

---

### 03. 重力与质量

- **公式与变形式**：
  $$G = mg \quad \Longleftrightarrow \quad m = \frac{G}{g}$$
- **各物理量含义与法定单位**：
  - $G$：重力（物体由于地球的吸引而受到的力），单位：牛顿（$\text{N}$），方向恒为**竖直向下**
  - $m$：质量（物体的基本属性），单位：千克（$\text{kg}$）
  - $g$：重力与质量的比值，单位：牛每千克（N/kg），$g=9.8\ \mathrm{N/kg}$，粗略计算时可取 $10\ \mathrm{N/kg}$
- **适用条件**：地球表面附近的任何物体。
- **中考避坑要点**：
  1. **方向表述严谨**：重力的方向是“竖直向下”，绝不可写成“垂直向下”。
  2. **天平与测力计在失重环境**：在太空轨道失重状态下，天平无法称量质量，但弹簧测力计仍可测量拉力。

---

### 04. 固体与通用压强

- **公式与变形式**：
  $$p = \frac{F}{S} \quad \Longleftrightarrow \quad F = pS, \quad S = \frac{F}{p}$$
  $$p = \rho gh \quad (\text{仅适用于规则柱状固体水平静止放置在水平面上})$$
- **各物理量含义与法定单位**：
  - $p$：压强（物体单位面积上受到的压力），单位：帕斯卡（$\text{Pa}$），$1\text{ Pa} = 1\text{ N/m}^2$
  - $F$：压力（垂直作用在物体表面上的力），单位：牛顿（$\text{N}$）
  - $S$：受力面积（两物体相互接触挤压的公共有效面积），单位：平方米（$\text{m}^2$）
- **适用条件**：固、液、气压强的基本定义式。
- **中考避坑要点**：
  1. **解题常规思路**：固体压强通常**先求压力**（水平面静止时 $F = G = mg$），**再求压强** $p = F/S$。
  2. **受力面积易错点**：受力面积 $S$ 必为接触面的实际受力部分。人站立为双脚底面积，行走时为单脚底面积；小汽车为四轮接地面积。换算注意：$1\text{ cm}^2 = 10^{-4}\text{ m}^2$。

---

### 05. 液体内部压强

- **公式与变形式**：
  $$p = \rho g h \quad \Longleftrightarrow \quad h = \frac{p}{\rho g}, \quad \rho = \frac{p}{gh}$$
- **各物理量含义与法定单位**：
  - $p$：液体压强，单位：帕斯卡（$\text{Pa}$）
  - $\rho$：液体密度，单位：千克每立方米（$\text{kg/m}^3$）
  - $g$：重力与质量的比值，单位：$\text{N/kg}$
  - $h$：深度（研究点到自由液面的**垂直竖直距离**），单位：米（$\text{m}$）
- **适用条件**：静止液体内部；同一液体同一深度各个方向的压强均相等。
- **中考避坑要点**：
  1. **深度 $h$ 的严格定义**：深度是指所求点到**自由液面**的垂直竖直距离，绝不是从容器底部往上量的高度。
  2. **容器底受力区分**：液体对容器底部的压力计算应**先算压强 $p = \rho gh$，再算压力 $F = pS$**。仅当直壁柱形容器时，底面受到的压力才恰好等于液体重力 $F = G_{\text{液}}$。

---

### 06. 浮力体系（全套四法）

- **公式体系**：
  1. **称重法**：
     $$F_{\text{浮}} = G - F_{\text{拉}} \quad (F_{\text{拉}}\text{为物体浸入液体后弹簧测力计的拉力示数})$$
  2. **压力差法（浮力产生本质）**：
     $$F_{\text{浮}} = F_{\text{向上}} - F_{\text{向下}}$$
  3. **阿基米德原理（普适计算式）**：
     $$F_{\text{浮}} = G_{\text{排}} = m_{\text{排}}g = \rho_{\text{液}} g V_{\text{排}}$$
  4. **平衡法（漂浮或悬浮状态）**：
     $$F_{\text{浮}} = G_{\text{物}} = m_{\text{物}}g = \rho_{\text{物}} g V_{\text{物}}$$
- **各物理量含义与法定单位**：
  - $F_{\text{浮}}$：浮力（液体对浸在其中的物体竖直向上的托力），单位：牛顿（$\text{N}$）
  - $\rho_{\text{液}}$：液体密度（物体浸入的液体密度，非物体本身密度），单位：$\text{kg/m}^3$
  - $V_{\text{排}}$：排开液体的体积（物体浸在液体中的部分的体积），单位：$\text{m}^3$
- **适用条件与物态判断**：
  - **漂浮**：$\rho_{\text{物}} < \rho_{\text{液}}$，此时 $F_{\text{浮}} = G_{\text{物}}$，且 $\frac{V_{\text{排}}}{V_{\text{物}}} = \frac{\rho_{\text{物}}}{\rho_{\text{液}}}$（部分浸入）。
  - **悬浮**：$\rho_{\text{物}} = \rho_{\text{液}}$，此时 $F_{\text{浮}} = G_{\text{物}}$，且 $V_{\text{排}} = V_{\text{物}}$（全部浸没，可在液体中任意深度静止）。
  - **沉底**：$\rho_{\text{物}} > \rho_{\text{液}}$，此时 $F_{\text{浮}} = \rho_{\text{液}} g V_{\text{物}} < G_{\text{物}}$，支持力 $F_{\text{支}} = G_{\text{物}} - F_{\text{浮}}$。
- **中考避坑要点**：
  1. 浸没状态下，$V_{\text{排}} = V_{\text{物}}$，浮力与物体在液体中所处的深度无关。
  2. 桥墩等底部与河床紧密贴合、底部没有液体压强的物体不受浮力（压力差法中 $F_{\text{向上}} = 0$）。

### 07. 同一直线上二力的合成

- **公式与规律**：
  $$F = F_1 + F_2 \quad (\text{同向，合力方向与两力相同})$$
  $$F = F_1 - F_2 \quad (F_1 > F_2,\ \text{反向，合力方向与较大的力相同})$$
  两力大小相等、方向相反时，合力为 0。
- **各物理量含义与法定单位**：
  - $F$：合力，单位：牛顿（$\text{N}$）
  - $F_1, F_2$：同一直线上的两个力，单位：牛顿（$\text{N}$）
- **中考避坑要点**：
  1. 先判断两力方向：同向相加，反向用较大的力减去较小的力。
  2. 合力大小和方向都要写；合力为 0 时不写方向。

### 08. 杠杆平衡条件

- **公式与变形式**：
  $$F_1 l_1 = F_2 l_2 \quad \Longleftrightarrow \quad \frac{F_1}{F_2} = \frac{l_2}{l_1}$$
- **各物理量含义与法定单位**：
  - $F_1$：动力（促使杠杆转动的力），单位：牛顿（$\text{N}$）
  - $l_1$：动力臂（从支点到动力作用线的**垂线段距离**），单位：米（$\text{m}$）
  - $F_2$：阻力（阻碍杠杆转动的力），单位：牛顿（$\text{N}$）
  - $l_2$：阻力臂（从支点到阻力作用线的**垂线段距离**），单位：米（$\text{m}$）
- **适用条件**：杠杆处于静止状态或匀速转动平衡状态。
- **中考分类与避坑**：
  1. **力臂作图**：力臂是**支点到力的作用线的垂直距离**，绝不是支点到力的作用点的距离。
  2. **三类杠杆判断**：
     - 省力杠杆：$l_1 > l_2 \implies F_1 < F_2$（省力费距离，如撬棒、羊角锤、开瓶器）。
     - 费力杠杆：$l_1 < l_2 \implies F_1 > F_2$（费力省距离，如筷子、镊子、钓鱼竿）。
     - 等臂杠杆：$l_1 = l_2 \implies F_1 = F_2$（如天平）。
  3. **求最小动力**：在杠杆上找距离支点最远的点作为作用点，并使力的方向与该点与支点的连线垂直。

### 09. 滑轮与滑轮组

- **公式与规律**：
  - **定滑轮**：
    $$F = G_{\text{物}}, \quad s = h, \quad v_{\text{绳}} = v_{\text{物}} \quad (\text{实质为等臂杠杆，不省力但改变施力方向})$$
  - **动滑轮（竖直提升，忽略绳重及摩擦）**：
    $$F = \frac{1}{2}(G_{\text{物}} + G_{\text{动}}), \quad s = 2h, \quad v_{\text{绳}} = 2v_{\text{物}} \quad (\text{实质为动力臂为阻力臂2倍的杠杆})$$
  - **滑轮组（竖直提升，忽略绳重及摩擦）**：
    $$F = \frac{1}{n}(G_{\text{物}} + G_{\text{动}}), \quad s = nh, \quad v_{\text{绳}} = nv_{\text{物}}$$
  - **滑轮组（水平拉动物体，克服摩擦力 $f$）**：
    $$F = \frac{1}{n}f, \quad s_{\text{绳}} = n s_{\text{物}}$$
- **各物理量含义与法定单位**：
  - $F$：绳子自由端的拉力，单位：牛顿（$\text{N}$）
  - $G_{\text{物}}, G_{\text{动}}$：物重与动滑轮重，单位：牛顿（$\text{N}$）
  - $n$：承担动滑轮和物重的有效绳子段数，无量纲正整数
  - $s$：绳子自由端移动距离；$h$：物体升高的距离，单位：米（$\text{m}$）
- **中考避坑要点**：
  1. **绳子段数 $n$ 的判定**：只数与**动滑轮直接相连**的绳子段数；若自由端从定滑轮向下引出，则该段拉力绳不计入 $n$。

### 10. 机械功

- **公式与变形式**：
  $$W = F s$$
  $$W = Gh \quad (\text{克服物体自身重力做功})$$
- **各物理量含义与法定单位**：
  - $W$：功，单位：焦耳（$\text{J}$），$1\text{ J} = 1\text{ N}\cdot\text{m}$
  - $F$：作用在物体上的力，单位：牛顿（$\text{N}$）
  - $s$：物体在**力的方向上**通过的距离，单位：米（$\text{m}$）
- **适用条件**：力和物体沿力的方向移动的距离。
- **中考避坑要点（做功的两个必要因素）**：
  1. 必须同时具备：① 作用在物体上的力；② 物体在**这个力的方向上**移动了一段距离。
  2. **不做功的三种常见情景**：
     - 不劳无功：物体靠惯性运动，没有力做功（如踢出的足球在草地上滚动）。
     - 不动无功：有力作用，但物体没有移动（如推车推而未动、搬石未动）。
     - 垂直无功：运动方向与力的方向垂直（如提着水桶在水平路面上匀速前行，提力不做功）。

---

### 11. 功率

- **公式与变形式**：
  $$P = \frac{W}{t}$$
  $$P = F v \quad (\text{当物体在力 } F \text{ 作用下做匀速直线运动时})$$
- **各物理量含义与法定单位**：
  - $P$：功率（表示物体做功快慢的物理量），单位：瓦特（$\text{W}$），常用单位千瓦（$\text{kW}$），$1\text{ kW} = 10^3\text{ W}$
  - $W$：做功多少，单位：焦耳（$\text{J}$）
  - $t$：做功所用时间，单位：秒（$\text{s}$）
  - $v$：物体匀速运动速度，单位：米每秒（$\text{m/s}$）
- **中考避坑要点**：
  1. **物理概念辨析**：功率大只表示做功**快**，不代表做功**多**（还取决于时间），更不代表机械效率高。
  2. **汽车爬坡换挡原理**：由 $P = Fv$ 可知，在发动机输出功率 $P$ 一定时，要获得更大的牵引力 $F$，必须降低汽车行驶速度 $v$（挂低速挡）。

---

### 12. 机械效率

- **公式体系**：
  - **机械效率基本通式**：
    $$\eta = \frac{W_{\text{有}}}{W_{\text{总}}} \times 100\% = \frac{W_{\text{有}}}{W_{\text{有}} + W_{\text{额}}} \times 100\%$$
  - **竖直提升滑轮组**：
    $$\eta = \frac{Gh}{Fs} = \frac{Gh}{F(nh)} = \frac{G}{nF}$$
    $$\text{若忽略绳重及摩擦: } \eta = \frac{G_{\text{物}}}{G_{\text{物}} + G_{\text{动}}} \times 100\%$$
  - **水平拉动物体滑轮组**：
    $$\eta = \frac{W_{\text{有}}}{W_{\text{总}}} = \frac{f s_{\text{物}}}{F s_{\text{绳}}} = \frac{f}{nF}$$
  - **斜面机械**：
    $$\eta = \frac{W_{\text{有}}}{W_{\text{总}}} = \frac{Gh}{FL} = \frac{Gh}{Gh + fL} \quad (L\text{为斜面长}, h\text{为斜面高}, f\text{为摩擦阻力})$$
- **各物理量含义与法定单位**：
  - $\eta$：机械效率（百分比，无量纲量，恒有 $\eta < 100\%$）
  - $W_{\text{有}}$：有用功（达到做功目的必须做的功，竖直提升时 $W_{\text{有}} = G_{\text{物}}h$），单位：焦耳（$\text{J}$）
  - $W_{\text{额}}$：额外功（克服机械自重与摩擦不得不做的无用功），单位：焦耳（$\text{J}$）
  - $W_{\text{总}}$：总功（实际动力所施加的全部功，$W_{\text{总}} = Fs$），单位：焦耳（$\text{J}$）
- **中考避坑要点**：
  1. 因为机械自重和摩擦的存在，额外功不可避免，$W_{\text{总}} > W_{\text{有}}$，因此**机械效率永远小于 $100\%$**。
  2. 提高滑轮组机械效率的有效途径：① 增加物重 $G_{\text{物}}$（有用功比例增大）；② 减轻动滑轮自重 $G_{\text{动}}$，对轮轴润滑以减小摩擦。

## 二、 热学与内能

重点考查比热容吸放热计算、热值公式、热机四个冲程特点与热机效率。

### 13. 比热容与热量计算

- **公式与变形式**：
  $$Q = cm\Delta t$$
  $$Q_{\text{吸}} = cm(t - t_0) \quad (\text{吸热升温})$$
  $$Q_{\text{放}} = cm(t_0 - t) \quad (\text{放热降温})$$
  $$Q_{\text{吸}} = Q_{\text{放}} \quad (\text{不计热损失时的热平衡方程})$$
- **各物理量含义与法定单位**：
  - $Q$：热量（热传递过程中内能转移的量度），单位：焦耳（$\text{J}$）
  - $c$：比热容（一定质量的某种物质，在温度升高时吸收的热量与它的质量和升高的温度乘积之比；数值上等于 1 kg 该物质温度升高 1 ℃ 吸收的热量），单位：焦每千克摄氏度（$\text{J/(kg}\cdot{^\circ}\text{C)}$）
  - $m$：质量，单位：千克（$\text{kg}$）
  - $\Delta t$：温度变化量，单位：摄氏度（$^\circ\text{C}$）
  - $t_0, t$：物体的初温和末温，单位：摄氏度（$^\circ\text{C}$）
- **适用条件**：物质没有发生物态变化（未发生熔化、凝固、沸腾等）时的升降温过程。
- **中考避坑要点**：
  1. **常数识记**：水的比热容 $c_{\text{水}} = 4.2 \times 10^3\text{ J/(kg}\cdot{^\circ}\text{C)}$，水常用于汽车冷却液和暖气供暖介质。
  2. **审题文字陷阱**：“升高了”、“降低了”指的是**温度差 $\Delta t$**；“升高到”、“降低到”指的是**末温 $t$**。

### 14. 燃料完全燃烧放热

- **公式与变形式**：
  $$Q_{\text{放}} = mq \quad (\text{固体或液体燃料})$$
  $$Q_{\text{放}} = Vq \quad (\text{气体燃料})$$
- **各物理量含义与法定单位**：
  - $Q_{\text{放}}$：燃料完全燃烧释放的热量，单位：焦耳（$\text{J}$）
  - $m$：燃料质量，单位：千克（$\text{kg}$）
  - $V$：气体燃料体积，单位：立方米（$\text{m}^3$）
  - $q$：热值（$1\text{ kg}$ 或 $1\text{ m}^3$ 某种燃料完全燃烧放出的热量），单位：$\text{J/kg}$ 或 $\text{J/m}^3$
- **适用条件**：燃料**完全燃烧**。
- **中考避坑要点**：
  1. 热值 $q$ 是燃料自身的固有特性，只与燃料种类有关，与燃料的质量、体积及是否充分燃烧无关。
  2. 注意单位对应：固态液态用 $\text{J/kg}$，气态（天然气、煤气）用 $\text{J/m}^3$。

---

### 15. 热机效率

- **公式与变形式**：
  $$\eta = \frac{W_{\text{有}}}{Q_{\text{放}}} \times 100\% = \frac{W_{\text{机械}}}{mq} \times 100\% = \frac{Pt}{mq} \times 100\%$$
- **各物理量含义与法定单位**：
  - $\eta$：热机效率（百分比，无量纲，通常汽油机约 $20\%\sim 40\%$，柴油机约 $30\%\sim 45\%$）
  - $W_{\text{有}}$：用来做有用功的机械能量（如汽车克服阻力做的功 $W = Fs$ 或 $Pt$），单位：焦耳（$\text{J}$）
  - $Q_{\text{放}}$：燃料完全燃烧释放的总化学能（$Q_{\text{放}} = mq$），单位：焦耳（$\text{J}$）
- **中考避坑要点**：
  1. **四冲程规律**：一个工作循环包括吸气、压缩、做功、排气 4 个冲程。曲轴与飞轮转动 **2 周**，活塞往复运动 **2 次**，对外做功 **1 次**。
  2. 压缩冲程：机械能转化为内能；做功冲程：内能转化为机械能。

---

## 三、 电学与电磁学

综合大题与实验探究核心，重点考查欧姆定律、电路分析、电功率及焦耳定律。

### 16. 电荷量与电流

**补充**（课本没有列出，了解即可）

- **公式与变形式**：
  $$I = \frac{Q}{t} \quad \Longleftrightarrow \quad Q = It, \quad t = \frac{Q}{I}$$
- **各物理量含义与法定单位**：
  - $I$：电流（表示电流强弱的物理量），单位：安培（$\text{A}$）
  - $Q$：电荷量，单位：库仑（$\text{C}$）
  - $t$：通电时间，单位：秒（$\text{s}$）
- **适用条件**：恒定直流电流。
- **中考避坑要点**：
  1. 电流方向规定：**正电荷定向移动的方向为电流方向**。在金属导体中，导电的是带负电的自由电子，其定向移动方向与电流方向**相反**。
  2. 换算关系：$1\text{ A} = 10^3\text{ mA} = 10^6\ \mu\text{A}$。

---

### 17. 欧姆定律

- **公式与变形式**：
  $$I = \frac{U}{R} \quad \Longleftrightarrow \quad U = IR, \quad R = \frac{U}{I}$$
- **各物理量含义与法定单位**：
  - $I$：通过该导体的电流，单位：安培（$\text{A}$）
  - $U$：该导体两端的电压，单位：伏特（$\text{V}$）
  - $R$：该导体的电阻，单位：欧姆（$\Omega$）
- **适用条件**：纯电阻电路；公式中的 $I, U, R$ 必须满足**同体性**（针对同一段导体）和**同时性**（针对同一状态/同一时刻）。
- **中考避坑要点**：
  1. **概念本质辨析**：电阻是导体本身的性质，由导体的材料、长度、横截面积及温度决定，**与导体两端是否加电压、是否有电流通过完全无关**。绝不能根据 $R = U/I$ 误判“导体的电阻与电压成正比，与电流成反比”。

---

### 18. 串联电路基本规律与推论

- **核心规律公式**：
  $$\text{电流规律: } I = I_1 = I_2 = \dots = I_n \quad (\text{处处相等})$$
  $$\text{电压规律: } U = U_1 + U_2 + \dots + U_n \quad (\text{总电压等于各分电压之和})$$
  $$\text{总电阻规律: } R = R_1 + R_2 + \dots + R_n \quad (\text{总电阻大于任一分电阻})$$
  $$\text{分压比推论: } \frac{U_1}{U_2} = \frac{R_1}{R_2}, \quad \frac{U_1}{U_{\text{总}}} = \frac{R_1}{R_{\text{总}}}$$
  $$\text{功率与电热分配: } \frac{P_1}{P_2} = \frac{W_1}{W_2} = \frac{Q_1}{Q_2} = \frac{R_1}{R_2}$$
- **中考避坑要点**：
  1. 串联电路特点是“**等流分压**”。电阻越大，分得的电压越大，消耗的功率也越大（因为 $P = I^2R$）。
  2. 动态电路中，滑动变阻器阻值变大时，回路总电阻变大，总电流变小，滑动变阻器两端分得的电压增大。

---

### 19. 并联电路基本规律与推论

- **核心规律公式**：
  $$\text{电压规律: } U = U_1 = U_2 = \dots = U_n \quad (\text{各支路两端电压相等})$$
  $$\text{电流规律: } I = I_1 + I_2 + \dots + I_n \quad (\text{干路电流等于各支路电流之和})$$
  $$\text{总电阻规律: } \frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} \iff R = \frac{R_1 R_2}{R_1 + R_2} \quad (\text{两电阻并联})$$
  **补充**（课本没有列出，做真题时常用）
  $$\text{分流比推论: } \frac{I_1}{I_2} = \frac{R_2}{R_1}, \quad \frac{I_1}{I} = \frac{R_2}{R_1 + R_2}$$
  $$\text{功率与电热分配: } \frac{P_1}{P_2} = \frac{W_1}{W_2} = \frac{Q_1}{Q_2} = \frac{R_2}{R_1}$$
- **中考避坑要点**：
  1. 并联电路特点是“**等压分流**”。电阻越大，流过的电流越小，消耗的功率也越小（因为 $P = \frac{U^2}{R}$）。
  2. 独立性：各支路用电器互不影响。某一支路开关断开，其他支路两端电压和工作状态完全保持不变（但干路总电流会变小）。

---

### 20. 电功与电能

- **公式体系**：
  $$\text{普遍适用公式: } W = UIt = Pt$$
  $$\text{纯电阻电路推导式: } W = I^2Rt = \frac{U^2}{R}t$$
  $$\text{家用电能表计算: } W = \frac{n}{N}\text{ kW}\cdot\text{h} = \frac{n}{N} \times 3.6 \times 10^6\text{ J}$$
- **各物理量含义与法定单位**：
  - $W$：电功或消耗的电能，单位：焦耳（$\text{J}$）或千瓦时（度，$\text{kW}\cdot\text{h}$）
  - $N$：电能表常数（如 $3000\text{ r/(kW}\cdot\text{h)}$ 或 $1600\text{ imp/(kW}\cdot\text{h)}$）
  - $n$：某段时间内电能表实际转动的圈数（$\text{r}$）或闪烁脉冲数（$\text{imp}$）
- **适用条件**：$W = UIt$ 对任何电路均成立；纯电阻推导式只适用于白炽灯、电炉、电热毯等纯电阻元件。
- **中考避坑要点**：
  1. 单位换算：$1\text{ 度} = 1\text{ kW}\cdot\text{h} = 3.6 \times 10^6\text{ J}$。
  2. 电能表表盘读数：窗口中最右边红框内为**十分位（小数位）**。

---

### 21. 电功率

- **公式体系**：
  $$\text{普遍适用定义式: } P = \frac{W}{t} = UI$$
  $$\text{纯电阻电路推导式: } P = I^2R = \frac{U^2}{R}$$
  $$\text{额定与实际关系: } R = \frac{U_{\text{额}}^2}{P_{\text{额}}}, \quad P_{\text{实}} = \left(\frac{U_{\text{实}}}{U_{\text{额}}}\right)^2 P_{\text{额}} \quad (\text{假设电阻 } R \text{ 不变})$$
- **各物理量含义与法定单位**：
  - $P$：电功率（表示用电器消耗电能快慢的物理量），单位：瓦特（$\text{W}$）或千瓦（$\text{kW}$）
  - $U_{\text{额}}, P_{\text{额}}$：额定电压与额定功率（铭牌标注值）
  - $U_{\text{实}}, P_{\text{实}}$：实际电压与实际电功率
- **中考避坑要点**：
  1. 灯泡的明暗程度**完全由其实际功率 $P_{\text{实}}$ 决定**，与额定功率无关。
  2. 纯电阻公式选用原则：串联电路电流相等，优先用 $P = I^2R$；并联电路电压相等，优先用 $P = \frac{U^2}{R}$。

---

### 22. 焦耳定律与电热

- **公式体系**：
  $$\text{焦耳定律普适式: } Q = I^2Rt$$
  $$\text{纯电阻电路: } Q = W = Pt = UIt = \frac{U^2}{R}t$$
  $$\text{非纯电阻电路(电动机等): } W_{\text{总}} = UIt, \quad Q_{\text{内}} = I^2Rt, \quad W_{\text{机械}} = W_{\text{总}} - Q_{\text{内}} = UIt - I^2Rt$$
- **各物理量含义与法定单位**：
  - $Q$：电流通过导体产生的热量，单位：焦耳（$\text{J}$）
  - $R$：发热导体的电阻，单位：欧姆（$\Omega$）
- **中考避坑要点**：
  1. 只有纯电阻电路中电能才全部转化为热能（$Q = W$）。
  2. **在含有电动机、电风扇的非纯电阻电路中**：$W_{\text{电}} > Q_{\text{热}}$，消耗的总电能必须用 $W = UIt$ 计算，线圈发热必须用 $Q = I^2Rt$ 计算，**严禁用 $W = \frac{U^2}{R}t$ 计算电动机的总电能**！

---

### 23. 电热综合效率（电水壶等加热器）

- **公式与变形式**：
  $$\eta = \frac{Q_{\text{吸}}}{W_{\text{电}}} \times 100\% = \frac{cm\Delta t}{Pt} \times 100\% = \frac{cm(t - t_0)}{UIt} \times 100\%$$
- **适用条件**：家用电热水器、电热水壶、电饭煲加热液体。
- **中考避坑要点**：
  1. 若题干明确说明“不计热量散失”，则意味着 $\eta = 100\%$，即 $Q_{\text{吸}} = W_{\text{电}}$。
  2. 计算水吸收热量时，注意若给出的是体积 $V$（例如 $2\text{ L}$），需先由 $m = \rho V$ 转化为质量（$2\text{ kg}$）后再代入计算。

---

### 24. 电磁波波速、波长与频率

- **公式与变形式**：
  $$c = \lambda f \quad \Longleftrightarrow \quad \lambda = \frac{c}{f}, \quad f = \frac{c}{\lambda}$$
- **各物理量含义与法定单位**：
  - $c$：电磁波在真空（或空气）中的传播速度，常数 $c = 3.0 \times 10^8\text{ m/s}$
  - $\lambda$：波长（相邻两波峰或波谷间的距离），单位：米（$\text{m}$）
  - $f$：频率（波源每秒振动次数），单位：赫兹（$\text{Hz}$）
- **中考避坑要点**：
  1. 真空中所有波长的电磁波（无线电波、红外线、可见光、紫外线、X射线等）传播速度都相同，都等于光速 $c$。
  2. 波长与频率**成反比**：频率越高的电磁波，波长越短。

## 四、 声现象与光现象

### 25. 声音传播与回声测距

- **公式与变形式**：
  $$v = \frac{s}{t} \quad \Longleftrightarrow \quad s = vt$$
  $$s_{\text{单程}} = \frac{1}{2} v_{\text{声}} t \quad (\text{静止声源向障碍物发声回声测距})$$
- **各物理量含义与法定单位**：
  - $s_{\text{单程}}$：声源到障碍物的直线距离，单位：米（$\text{m}$）
  - $v_{\text{声}}$：声速（$15^\circ\text{C}$ 空气中为 $340\text{ m/s}$，海水（25 ℃）中为 $1531\ \mathrm{m/s}$），单位：米每秒（$\text{m/s}$）
  - $t$：从发声到接收到回声经历的总时间，单位：秒（$\text{s}$）
- **中考避坑要点**：
  1. 静止回声测距计算**必须除以 2**。
  2. 人耳能区分回声与原声的最小时间间隔为 $0.1\text{ s}$（对应反射障碍物到人的距离至少为 $s = \frac{1}{2} \times 340 \times 0.1 = 17\text{ m}$）。

---

### 26. 光的反射与平面镜成像

- **规律**：
  1. 反射光线、入射光线和法线在同一平面内；反射光线、入射光线分居法线两侧；反射角等于入射角。
  2. 平面镜成像：像与物大小相等，像与物到镜面的距离相等，像与物的连线与镜面垂直，成的是虚像。
- **各物理量含义与法定单位**：
  - 入射角、反射角：分别是入射光线、反射光线与法线的夹角，单位：度（$^\circ$）
  - 像与物到镜面的距离：像、物到镜面的垂直距离，单位：米（$\text{m}$）
- **中考避坑要点**：
  1. 入射角和反射角都从法线量起，不是光线与镜面的夹角。
  2. 平面镜成的虚像不能用光屏承接；像的大小不随物体到镜面的距离改变。

---

### 27. 凸透镜成像规律速查表（课标必考）

> **三大关键分界点**：
> - **一倍焦距分虚实**：$u > f$ 成实像，$u < f$ 成虚像，$u = f$ 不成像。
> - **二倍焦距分大小**：$u > 2f$ 像缩小，$u < 2f$ 像放大，$u = 2f$ 像等大。
> - **动态成像口诀**（成实像时）：**物近像远像变大，物远像近像变小**。

| 物距条件 $u$ | 像距范围 $v$ | 像的性质（虚实 / 正倒 / 大小） | 像物相对位置 | 典型中考应用 |
| :--- | :--- | :--- | :--- | :--- |
| $u > 2f$ | $f < v < 2f$ | 倒立、缩小的**实像** | 异侧 | 照相机、智能手机摄像头 |
| $u = 2f$ | $v = 2f$ | 倒立、等大的**实像** | 异侧（物像间距最小为 $4f$） | 粗测凸透镜焦距 $f$ |
| $f < u < 2f$ | $v > 2f$ | 倒立、放大的**实像** | 异侧 | 投影仪、幻灯机、电影放映机 |
| $u = f$ | 不成像（平行光） | 不成像 | —— | 获得平行光束（探照灯） |
| $u < f$ | —— | 正立、放大的**虚像** | 同侧（像比物离透镜更远） | 放大镜、老花镜 |

## 七、 中考物理常见隐含条件与答题避坑要诀

| 题干常见关键词 / 语句 | 中考真实隐含物理条件 | 核心解题对应切入点 |
| :--- | :--- | :--- |
| **“光滑”、“不计摩擦”** | 接触面没有摩擦阻力 | 滑轮组额外功只考虑动滑轮重；若只有动能和势能相互转化，机械能守恒 |
| **“静止”、“匀速直线运动”** | 物体处于平衡状态，合外力为零 | 二力平衡：$F_{\text{合}} = 0$，牵引力等于摩擦阻力，$F = f$ |
| **“物体漂浮在液面上”** | 浮力等于物体重力；物体密度小于液体密度 | $F_{\text{浮}} = G_{\text{物}}$；排开体积比例 $\frac{V_{\text{排}}}{V_{\text{物}}} = \frac{\rho_{\text{物}}}{\rho_{\text{液}}}$ |
| **“物体悬浮在液体中”** | 浮力等于物体重力；物体密度等于液体密度 | $F_{\text{浮}} = G_{\text{物}}$；$V_{\text{排}} = V_{\text{物}}$，可在液体内任一点悬停 |
| **“物体沉底 / 容器底有支持力”** | 物体密度大于液体密度；浮力小于自身重力 | $F_{\text{浮}} + F_{\text{支}} = G_{\text{物}}$；$V_{\text{排}} = V_{\text{物}}$ |
| **“轻质杠杆 / 轻质滑轮”** | 杠杆或滑轮自身重力忽略不计 | 杠杆平衡时不考虑杠杆自重；滑轮省力计算无需加 $G_{\text{动}}$ |
| **“正常发光 / 正常工作”** | 实际工作电压等于额定电压 | $U_{\text{实}} = U_{\text{额}} \implies P_{\text{实}} = P_{\text{额}}$，通过电流 $I_{\text{实}} = I_{\text{额}}$ |
| **“用电器串联”** | 回路中通过各用电器的电流处处相等 | 优先选用 $P = I^2R$，电压比等于电阻比（等流分压） |
| **“用电器并联”** | 各支路用电器两端的电压相等且等于总电源电压 | 优先选用 $P = \frac{U^2}{R}$，电流比等于电阻反比（等压分流） |
| **“不计热量散失 / 理想加热”** | 释放的热量或消耗的电能 $100\%$ 被吸收 | 热平衡方程：$Q_{\text{吸}} = Q_{\text{放}}$；电热转换：$cm\Delta t = Pt$ |
| **“白气”** | 水蒸气遇冷液化形成的小水珠（不是气体！） | 发生物态变化为**液化**，过程向外放出热量 |
| **“做功冲程”** | 进气门、排气门均关闭，火花塞点火，活塞向下运动 | 内能转化为机械能；产生动力的唯一冲程 |
| **“自由端移动距离 $s$ 与物体升高 $h$”** | 滑轮组承担物重绳子段数 $n$ | $s = nh, \quad v_{\text{绳}} = nv_{\text{物}}$；千万不要颠倒成 $h = ns$ |
